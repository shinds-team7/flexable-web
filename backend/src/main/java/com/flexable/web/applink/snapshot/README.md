# applink/snapshot
project2에 연결하지 않는 어댑터(`APP_LINK_MODE=snapshot`, `local` 프로필 기본). 로컬 화면 확인과 인터넷 없는 시연에서 고정된 연동 결과를 돌려준다. 앱 코드 규칙(6자리, 0·1·I·L·O 제외)에 맞으면 연동된다. 가짜 앱 쪽 연동 목록(`linkId`)은 이 어댑터의 메모리에만 있어 재시작하면 사라진다. 웹 DB의 `app_links` 행은 남지만, 다음 조회에서 가짜 앱이 `LINK_NOT_FOUND`를 돌려주므로 웹도 해제된 것으로 처리해 행을 지운다. 실제 사용자 데이터를 넣지 않는다. 자동 테스트는 이 어댑터 대신 `AppApiClient`를 목으로 바꿔 끼운다.
