# news
청년 금융 소식 저장·조회(01 §F4). 수집은 worker(`ingest.YouthNewsSyncJob`)가 `NewsService.saveCollected`로 넣고, 화면은 `GET /youth-news`로 읽는다.

- 수집한 정책은 초안(`DRAFT`)이다. 사람이 검수해 나에게 얼마·오늘 할 일·대상 요약을 쓰고 승인(`APPROVED`)한 것만 화면에 나간다. 검수·승인 API는 아직 없다.
- 승인·반려된 카드는 다시 수집해도 덮어쓰지 않는다(원문만 갱신).
- 금액·기한은 원문 값만 쓰고, 원문에서 확인 못 한 값은 `null`이다(조건 없음이 아님).
- 필터(나이·지역·분야)는 쿼리로만 받고 저장하지 않는다.
