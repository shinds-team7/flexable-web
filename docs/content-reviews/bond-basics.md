## 계산 확인(규칙 9)

```js
// node로 실행 — 액면 100만 원, 연 10%, 만기 3년, 1년에 한 번 이자(예시)
const face = 1000000, rate = 0.10, years = 3;
console.log(face * rate);                  // 100000  (1년 이자)
console.log(face * rate * years + face);   // 1300000 (3년간 받는 이자 합계 + 원금)
```

## 자료끼리 다른 점(규칙 7)

- 금감원 실용금융 (4)는 "채권은 발행자의 파산 시를 제외하고는 법적으로 원근(원금) 보장이 가능"이라고 말한다. 한편 같은 자료는 만기 전 매도 때의 시장위험도 설명한다. 원고는 '원금 보장'이라는 표현을 쓰지 않았다. 대신 만기 보유와 만기 전 매도를 나누고, 채무불이행 위험을 적었다.

## 원고에서 뺀 내용

- 채권 매매차익(가격이 올라 팔 때 생긴 이익)의 과세: 공식 자료로 확인하지 않아 넣지 않았다. 원고의 세금 설명은 이자에만 해당한다.
- 이표채·할인채·복리채, 보증채·무보증채, 전환사채 등 특수한 채권: 금감원 원문은 확인했으나 글 길이 때문에 뺐다. 계산식 캡션에 '1년에 한 번 이자를 주는 채권'이라고 적어 이표채 예시임을 밝혔다.
- 신용등급과 금리(신용이 낮을수록 이자를 더 줌): 한국은행 2016년 어린이 영상에만 있어 넣지 않았다.
- 듀레이션(만기가 길수록 금리 변동에 가격이 더 크게 움직임): 검색 요약에는 있었으나 원문 대조를 하지 않아 넣지 않았다.
- 현재 국고채 금리: 자주 바뀌는 수치라 넣지 않았다(규칙 12).
- 국채전문유통시장·REPO·소액채권시장: 한국거래소 원문은 확인했으나 대상 독자에게 우선순위가 낮아 뺐다.

## 사람이 확인할 것

- 채권의 정의·위험 설명은 금감원 교육 영상 자막(제작 시점 표시 없음)과 한국은행 2008·2015·2024년 교육 자료다.
- 예시 금리 연 10%는 한국은행 교육 자료의 예시를 그대로 따랐다. 현재 금리처럼 보이지 않도록 캡션에 '예시'를 붙였다.
