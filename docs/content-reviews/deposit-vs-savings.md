## 계산 확인(규칙 9)

```js
// node로 실행 — 매달 10만 원, 12개월, 연 5% 단리 적금(예시)
const m = 100000, r = 0.05, n = 12;
const pre = m * r * (n * (n + 1) / 2) / 12;      // 32500 (세전 이자)
const inc = Math.floor(pre * 0.14);              // 4550  (소득세)
const loc = Math.floor(inc * 0.1);               // 455   (지방소득세)
console.log(pre, inc + loc, pre - inc - loc);    // 32500 5005 27495
console.log(m * 0.0423 * (n + 1) / 2);           // 27495 (금감원 표의 세후 이자율 4.23% 방식과도 같음)
console.log(1200000 * r);                        // 60000 (같은 금리로 120만 원을 1년 예금)
```

## 원고에서 뺀 내용

- (바로잡음) 처음 작성 때 파인 '중도 해약 전 알아두세요'(dp019)·'예·적금 체크 리스트'(dp025)는 주소에 `menuNo`가 없어 오류 페이지로 넘어가 읽지 못했다. 2차 검수에서 `?menuNo=900230`을 붙여 열었고, 중도해지 내용을 예·적금 전체로 고쳤다.
- 정기예금 일부해지 서비스, 예금담보대출 비교: dp019에 있으나 글 범위를 넘어 뺐다.
- 주거래은행 우대·가족 거래실적 합산: 파인 '유용한 꿀팁'에 있으나 글 길이 때문에 뺐다.
- 상호금융·우체국 예금 보호: 예금보험공사가 아니라 각 법령에 따른 자체 기금으로 보호해 원고 범위를 '은행·저축은행'으로 한정했다.
- 회전식 정기예금, 금리 인상기 만기 선택: 확인했으나 글 범위를 넘어 뺐다.
- 금융상품한눈에 상품명·금리: 특정 상품 추천이 될 수 있어 넣지 않았다(규칙 11).

## 자료끼리 다른 점(규칙 7)

- 금융상품한눈에 도움말의 "2022.2.18. 기준 … 연간 2천만원 이상일 경우 종합소득세가 부과될 수 있습니다"는 국세청 Q&A("2천만원을 초과하는 경우")와 표현이 다르다. 이 글에는 넣지 않았다.

## 검수에서 고친 것

| 지적 | 고친 내용 |
|---|---|
| (2차) 중도해지를 예금으로만 한정해 적금은 손해가 없는 것처럼 읽힘(파인 dp019는 예·적금 전체 안내) | "예·적금을 만기 전에 해지하면 … 낮은 중도해지 금리, 가입 기간에 따라 달라요"로 고치고 dp019를 출처에 추가 |

- 1차 검수에서는 인용 17곳이 모두 일치해 고친 문장이 없었다.

## 사람이 확인할 것

- 적금 이자 계산 설명(넣은 돈마다 기간이 다름)은 공식 문장이 아니라 단리 정의에서 나온 계산이다. 금감원 예시 금액과 결과가 같은 것을 확인했다.
