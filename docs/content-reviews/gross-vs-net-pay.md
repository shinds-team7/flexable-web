## 계산 확인(규칙 9)

```js
// node로 실행
const pay = 3000000;
console.log(pay * 4.75 / 100);              // 142500 국민연금(근로자 몫)
console.log(7.19 / 2, 1.8 / 2);             // 3.595 0.9
console.log(pay * 3.595 / 100);             // 107850 건강보험(근로자 몫, 끝수 처리 전)
console.log(pay * 0.9 / 100);               // 27000  고용보험(근로자 몫)
console.log(50000 * 10 / 100);              // 5000   지방소득세(소득세 5만 원 가정)
console.log(107850 * 13.14 / 100);          // 14171.49 (복지부 13.14% 기준)
console.log(107850 * 0.9448 / 7.19);        // 14172    (공단 산식 0.9448%/7.19% 기준)
```

## 자료끼리 다른 점(규칙 7)

- 국민연금 보험료율: 국민연금법 제88조 ③ 본문은 사업장가입자의 기여금과 부담금을 "각각 기준소득월액의 1천분의 65"로 적는다(합계 13%). 국민연금공단과 보건복지부는 2026년 보험료율을 9.5%(근로자 4.75%)로 안내하고, 2033년 13%까지 해마다 0.5%p씩 올린다고 한다. 본문은 최종 수치이고 연도별 단계 적용은 부칙에 있을 것으로 보이나, 부칙 원문은 대조하지 않았다. 원고에는 2026년 적용 값(공단·복지부)을 썼다.
- 장기요양보험료: 복지부는 "건강보험료 대비 13.14%", 공단 공지는 "건강보험료 × 0.9448% / 7.19%"로 적는다. 0.9448 ÷ 7.19 = 0.13140…이라 금액에 1원 안팎의 차이가 날 수 있다(위 코드). 원고 계산식에는 '약 14,171원'과 '계산 방식에 따라 1원 안팎 차이'를 함께 적었다.

## 원고에서 뺀 내용

- 국민연금 기준소득월액 상한·하한 금액: 공단 FAQ에서 금액 문장을 찾지 못했다. 계산식 캡션에 '기준소득월액이 월급과 같다고 가정'을 붙였다.
- 건강보험·장기요양보험료의 원 단위 끝수 처리 규정: 확인하지 않아 계산식 캡션에 '끝수 처리 전'·'약'을 붙였다.
- 근로소득 간이세액표의 구체 금액과 공제대상가족 수에 따른 차이: 별표 2 원문을 대조하지 않았다.
- 비과세 급여(식대 등)와 보수·과세 대상의 차이: 확인하지 않았다.
- 산재보험: 근로자 몫을 정한 조문을 찾지 않아 언급하지 않았다('4대 보험'이라는 말도 쓰지 않음).
- 장기요양보험료를 회사와 나누는 비율: 노인장기요양보험법 조문을 대조하지 않아 쓰지 않았다.
- 국민건강보험공단 공지에서 '가입자 및 사용자 각각 50%씩 부담' 문구: 검색 요약에는 있었지만 직접 받은 공지 본문에서 찾지 못했다. 같은 내용은 국민건강보험법 제76조로 확인했다.

## 검수에서 고친 것

| 지적 | 고친 내용 |
|---|---|

## 사람이 확인할 것

- 국민연금 보험료율의 법 본문(6.5%씩)과 2026년 적용 값(4.75%씩)의 차이. 부칙 원문 확인이 필요하면 따로 대조한다.
- 고용보험료 원천공제는 법 문구가 '할 수 있다'이다. 원고는 "먼저 떼고 줘요"로 일반적인 경우를 설명했다.
- FAQ 뒷문장은 제137조 계산 순서에서 나온 설명이다.
