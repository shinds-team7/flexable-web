## 계산 확인(규칙 9)

```js
// node로 실행
console.log(5 - 3, ((1.05 / 1.03 - 1) * 100).toFixed(4)); // 2  1.9417  → '대략' 표시 근거
console.log(5 - 5);                                       // 0
console.log(2 - 3, Math.round(1020000 / 1.03));           // -1  990291 → FAQ: 구매력이 맡기기 전(100만 원)보다 줄어듦
```

## 자료끼리 다른 점(규칙 7)

- 실질금리를 18. 이자율은 "대략" 명목 − 인플레이션율로, 21. 금융은 "명목금리에서 물가상승률을 뺀 금리"로 설명한다. 정확한 식으로는 약간 차이가 있어(5%·3%일 때 약 1.94%) 원고에는 '대략'을 붙였다.

## 원고에서 뺀 내용

- 현재 소비자물가 상승률: 자주 바뀌는 수치라 넣지 않았다(규칙 12). 현재 값을 안내할 공식 페이지(통계 작성기관)는 이번에 확인하지 않아 링크도 넣지 않았다. 참고로 한국은행 2024 자료는 소비자물가지수를 "통계청에서 작성"한다고 하고, 2026-10-22 한국은행 보도자료는 통계기관을 '국가데이터처'로 적는다. 작성기관 이름은 원고에 쓰지 않았다.
- 인플레이션의 원인(수요견인·비용인상, 통화량), 초인플레이션: 한국은행 자료로 확인했으나 글 범위를 넘어 뺐다.
- 물가안정목표 2%를 정한 이유: 검색 요약으로만 보았고 원문을 대조하지 않아 넣지 않았다.
