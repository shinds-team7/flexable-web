## 계산 확인(규칙 9)

```js
// node로 실행
const pre = 100000;                       // 세전 이자(예시)
const inc = Math.floor(pre * 14 / 100);   // 14000 소득세
const loc = Math.floor(inc * 10 / 100);   // 1400  개인지방소득세
console.log(inc, loc, inc + loc, pre - (inc + loc)); // 14000 1400 15400 84600
console.log(14 + 14 * 0.1);               // 15.4 (%)
```

## 원고에서 뺀 내용

- 끝수 처리: [국고금관리법 제47조](https://www.law.go.kr/법령/국고금관리법/제47조)(시행 2026-01-02) "국고금의 수입 또는 지출에서 10원 미만의 끝수가 있을 때에는 그 끝수는 계산하지 아니하고, 전액이 10원 미만일 때에도 그 전액을 계산하지 아니한다"를 확인했다. 금융회사의 원천징수에 그대로 적용되는지는 공식 설명을 찾지 못했다(확인 불가). 예시는 끝수가 생기지 않는 숫자(세전 이자 10만 원)로 정했다.
- 지방소득세 소액 면제: [지방세법 제103조의60](https://www.law.go.kr/법령/지방세법/제103조의60) "지방소득세로 징수할 세액이 고지서 1장당 2천원 미만인 경우에는 그 지방소득세를 징수하지 아니한다"가 특별징수(원천징수)에도 적용되는지 확인하지 못했다(확인 불가). FAQ는 소득세 규정만 다룬다.
- 종합과세 세율(기본세율)과 세액 계산 방법: 국세청 Q&A 안에서도 기본세율 표기가 "6~42%"로 적힌 곳이 있어 다른 국세청 세율표와 맞는지 확인하지 못했다(규칙 7). 글 범위 밖이라 넣지 않았다.
- 비과세·분리과세 상품 이름과 조건(ISA, 재형저축 등): 상품마다 조건이 달라 `isa-vs-pension` 등에서 다룬다.
- 배우자 금융소득 합산 여부(국세청 "배우자의 금융소득은 본인의 금융소득에 합산되지 않습니다"): 확인했으나 대상 독자에게 우선순위가 낮아 FAQ에 넣지 않았다.
- 종합소득세 신고 기간(다음 해 5월): 검색 요약으로만 보았고 원문을 대조하지 않아 넣지 않았다.
