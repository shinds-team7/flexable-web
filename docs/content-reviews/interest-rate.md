## 계산 확인(규칙 9)

```js
// node로 실행
console.log(1050000 - 1000000);       // 50000  → 이자 5만 원
console.log(50000 / 1000000 * 100);   // 5      → 금리 5%
console.log(1000000 * 5 / 100);       // 50000  → 1년 이자 5만 원
```

## 원고에서 뺀 내용

- 현재 기준금리 수치와 결정 날짜: 자주 바뀌는 값이라 규칙 12에 따라 넣지 않고 공식 페이지로 안내했다. 작성일에 확인한 값(2026-10-22 결정, 3.00% 유지)은 기록으로만 남긴다.
- 이자소득 원천징수 세율: 소득세법 제129조로 확인했으나 `interest-income-tax`의 주제라 '세금 떼기 전' 조건만 적었다.
- 고정금리·변동금리 정의: 금융감독원 금융상품한눈에(주택담보대출)에서 확인했으나 이 글의 범위 밖이라 뺐다. `loan-rate-repayment`에서 다룰 수 있다.
- 명목금리·실질금리: 한국은행 자료로 확인했으나 `inflation-real-rate`에서 다룬다. 참고로 18. 이자율은 실질이자율을 "명목이자율에서 인플레이션율을 차감한 것"이라며 가치 하락 정도가 "대략" 인플레이션율과 비슷하다고 설명하고, 21. 금융은 "명목금리에서 물가상승률을 뺀 금리"라고만 적는다(규칙 7: 표현 차이).
- "금리는 돈의 가격": 금리란 무엇일까요?(2020-12-09)에 "한마디로 금리는 돈의 가격입니다"가 있다. 글 흐름상 넣지 않았다. 처음 작성 때는 이 주소가 301 리다이렉트라 본문을 받지 못했고, 검수 때 리다이렉트를 따라가 확인했다.
