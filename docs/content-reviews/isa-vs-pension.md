## 계산 확인(규칙 9)

```js
// node로 실행
console.log(6000000 * 0.15, 6000000 * 0.12);       // 900000 720000 (세액공제 15%, 12%)
console.log((0.15 * 1.1 * 100).toFixed(1) + '%');  // 16.5% (기타소득 15% + 지방소득세 10%)
console.log(Math.min(30000000 * 0.1, 3000000));    // 3000000 (전환금액 3천만 원의 10%와 300만 원 중 적은 금액)
const lim = (y, cum) => 20000000 * (1 + Math.min(y, 4)) - cum; // ISA 연간 한도(조특법 제91조의18 산식)
console.log(lim(0, 0), lim(1, 0), lim(4, 0));      // 20000000 40000000 100000000 (못 채운 한도 이월, 총 1억 원)
console.log([5, 4, 3].map(x => (x * 1.1).toFixed(1))); // ['5.5','4.4','3.3'] (연금소득세 + 지방소득세)
```

## 자료끼리 다른 점(규칙 7)

- 비과세 한도: 금융상품한눈에 ISA 안내는 "금융소득 2백만원까지 비과세"만 적는다. 조세특례제한법 제91조의18 ②은 총급여 5천만 원 이하 등은 400만 원, 그 밖은 200만 원으로 나눈다. 원고는 법을 따랐다.
- 의무가입기간: 금융위원회 ISA 주요정책문답(도입 당시 자료)은 의무가입기간을 5년(일부 3년)으로 설명한다. 현행 법(계약기간 3년 이상, 3년 전 해지 시 추징)과 금감원 안내(3년 유지)를 따랐다.
- 2024년 1월 정부가 발표한 ISA 확대안(연 4천만 원·총 2억 원, 비과세 500만·1천만 원)은 2026-11-04 확인한 법 조문에 반영되어 있지 않아 쓰지 않았다.

## 원고에서 뺀 내용

- (바로잡음) ISA 연간 납입한도 산식과 연금소득세 나이별 세율은 처음에 조문 그림이라 대조하지 못했으나, 2차 검수에서 원본 HTML의 그림 대체 글(alt)로 확인해 원고에 반영했다.
- 종신계약 3%, 연금소득이 연 1,500만 원을 넘을 때의 과세 방식(종합과세 또는 분리과세 선택): 글 길이 때문에 뺐다. 원고에는 '1,500만 원 이하라면'으로 조건을 적었다.
- ISA 가입 제외(금융소득종합과세자)의 법 조문 위치: 이번에 찾지 못해 금감원 안내만 근거로 했다.
- 연금저축 부득이한 사유 인출(의료비 등) 때 낮은 세율, 퇴직소득 재원 연금 세율, ISA 중도해지 예외 사유의 세부 목록: 글 범위를 넘어 뺐다(사망·해외이주 등 '부득이한 사유는 제외'만 적음).
- 금융투자협회 'ISA 다모아'(수익률·수수료 비교): 확인하지 않았다.

## 사람이 확인할 것

- (해결) ISA 연간 납입한도 이월, 연금소득세 나이별 세율: 2차 검수에서 조문 그림의 대체 글로 확인했다.
- ISA→연금계좌 전환 방법(기한 포함)을 정한 시행령 조문은 찾지 못했다. 원고는 '정해진 방법으로'라고만 적었다.
- 연금저축펀드가 예금자보호 대상이 아니라는 문장은 예금보험공사 '펀드 비보호' 원문에서 나온 판단이다.
