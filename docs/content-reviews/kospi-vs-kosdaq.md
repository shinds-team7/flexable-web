## 자료끼리 다른 점(규칙 7)

- e-나라지표의 식은 "비교시점의 주식 시가총액 / 기준시점의 주식 시가총액 x 100" 하나뿐이다. 그런데 같은 페이지는 코스닥 종합지수의 기준값을 1,000이라고 적는다. 그래서 코스닥지수에는 이 식(× 100)을 그대로 쓸 수 없어 보인다. 원고의 계산식은 기준값이 100인 코스피지수로만 들었다.

## 원고에서 뺀 내용

- 현재 코스피·코스닥 지수와 시가총액: 자주 바뀌는 수치라 넣지 않았다(규칙 12). 지금 지수를 어디서 보는지 안내하는 문장도 뺐다. 글의 중심을 두 시장의 뜻과 차이에 두기로 했다(사람 결정, 2026-11-04). 한국거래소 페이지의 "시가총액 1,150조 원 규모"는 기준일이 없어 쓰지 않았다.
- 코스닥지수 기준값이 처음에는 100이었다가 2004년에 1,000으로 바뀌었다는 설명: 검색 결과의 백과사전·언론 자료에만 있어 공식 자료로 확인하지 못했다.
- 코스닥시장의 정규 매매시간·결제일: 한국거래소 코스닥 페이지에서 매매시간 표를 찾지 못했다. 시간외 종가매매가 "정규매매시간 종료 10분 후부터" 15:40에 시작한다는 원문만 확인해 정규시간을 적지 않았다.
- 두 시장의 증권거래세 차이: `stock-basics` 보고서와 같은 이유로 확정하지 못했다. 시행령 제5조(유가증권시장 1만분의 5, 코스닥시장 1만분의 20)는 확인했으나 농어촌특별세가 어느 시장에 붙는지는 확인하지 못했다.
- 두 시장의 구체적인 상장 요건(자기자본·매출액 등), 기술특례상장: 글 범위를 넘어 뺐다.
- 데이터 사이트 '주가지수 돋보기'(data.krx.co.kr): "서비스 제공 불가능 일시적 접근 불안정" 화면만 보여 읽지 못했다(규칙 8).
