## 계산 확인(규칙 9)

```js
// node로 실행 — 원고 예시: 1,200만 원, 연 5%, 12개월, 고정금리
const P = 12000000, r = 0.05 / 12, n = 12;
console.log(P * 0.05);                                    // 600000 (만기일시 1년 이자)
const pmt = P * r / (1 - Math.pow(1 + r, -n));            // 1027289.78 (원리금균등 월 상환액)
let b = P, i1 = 0; for (let k = 0; k < n; k++) { const it = b * r; i1 += it; b -= pmt - it; }
console.log(i1.toFixed(2));                               // 327477.38 (원리금균등 총 이자)
console.log(P * r * (n + 1) / 2, P / n + P * r, (P / n + (P / n) * r).toFixed(2)); // 325000 1050000 1004166.67

// 금융감독원 예시표 검산: 1억 원, 연 3%, 60개월
// 만기일시 총 이자 15,000,000 / 원리금균등 월 1,796,869, 총 이자 7,812,144(표 7,812,112) / 원금균등 1회차 1,916,667, 60회차 1,670,833, 총 이자 7,625,000(표 7,925,000)
```

## 자료끼리 다른 점(규칙 7)

- 금융상품한눈에 예시표(1억 원, 연 3%, 5년)의 원금균등분할상환 총 이자가 **7,925,000원**으로 적혀 있다. 같은 표의 회차별 금액(1,916,667원 … 1,670,833원)으로 계산하면 **7,625,000원**이다. 같은 페이지 본문도 원금균등을 "총 이자비용은 가장 적지만"이라고 하는데, 표의 7,925,000원은 원리금균등(7,812,112원)보다 커서 본문과도 맞지 않는다. 표의 숫자가 잘못 적힌 것으로 보여 원고에는 쓰지 않고, 직접 정한 예시를 코드로 계산해 넣었다.
- 같은 표의 원리금균등 총 이자 7,812,112원과 코드 결과 7,812,144원은 32원 차이로, 끝수 처리 차이로 보인다.

## 원고에서 뺀 내용

- 대출금리 구성(기준금리 + 가산금리 − 우대금리), COFIX 등 대출 기준금리: 검색 요약으로만 보았고 원문을 대조하지 않아 넣지 않았다.
- 은행 외 금융회사(보험·카드·저축은행 등)의 금리인하요구권: 은행법 조문만 확인해 '은행'으로 한정해 썼다.
- 중도상환수수료의 대통령령 예외 내용, 수수료율: 시행령을 대조하지 않아 넣지 않았다.
- LTV·DSR 등 대출 규제: 금융상품한눈에 페이지의 LTV 설명이 "2015년 12월 현재"로 오래된 기준이라 넣지 않았다.
- 금융상품한눈에의 상품명·금리: 특정 상품 추천이 될 수 있어 넣지 않았다(규칙 11).
