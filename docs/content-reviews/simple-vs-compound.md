## 계산 확인(규칙 9)

```js
// node로 실행
const P = 1000000;
const simple = (r, n) => P * r * n / 100;
const comp = (r, n) => Math.round(P * Math.pow(1 + r / 100, n) - P);
console.log(simple(5, 2), comp(5, 2));        // 100000 102500
console.log(P * 0.05, (P + P * 0.05) * 0.05); // 50000 52500 (1년째, 2년째 복리 이자)
for (const n of [1, 2, 5, 10, 20]) console.log(n, comp(5, n) - simple(5, n));
// 1 0 / 2 2500 / 5 26282 / 10 128895 / 20 653298
console.log(P + simple(10, 2), P + comp(10, 2)); // 1200000 1210000 (한국은행 21. 금융 예시와 일치)
```

## 원고에서 뺀 내용

- 월복리 1년 이자 금액: 연 5%를 12로 나눈 월 금리로 계산하면 51,161원(원 미만 버림)이지만, 실제 상품이 월 금리를 어떻게 정하는지 확인하지 못해 금액을 넣지 않았다.
- 적금(매달 넣는 돈)의 단리·복리 계산: 납입 시점마다 기간이 달라 계산 구조가 다르다. `deposit-vs-savings`에서 다룰 수 있다.
- 금융상품한눈에 검색 결과의 상품명·금리: 특정 상품 추천이 될 수 있어 넣지 않았다(규칙 11).
