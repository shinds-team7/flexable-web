## 계산 확인(규칙 9)

```js
// node로 실행 — 배당금 10만 원(예시)
const div = 100000;
const inc = Math.floor(div * 0.14);   // 14000 (소득세)
const loc = Math.floor(inc * 0.1);    // 1400  (지방소득세)
console.log(inc + loc, div - inc - loc); // 15400 84600
```

## 자료끼리 다른 점(규칙 7)

- 시간외 거래 시간: 금감원 실용금융 (4)는 "오후 4시부터 6시까지는 시간 외 거래"라고 설명한다. 한국거래소 매매거래제도일반 표는 장종료후 시간외 종가 15:40~16:00, 대량·바스켓 15:40~20:00, 애프터마켓 16:00~20:00이다. 금감원 영상은 제작 시점이 표시되지 않아 한국거래소 표를 따랐다. 원고에는 시각을 넣지 않고 '앞뒤로 시간외 거래가 따로 있다'고만 적었다.
- 금감원 실용금융 (4)는 주식 매매에 "거래세와 농어촌특별세"가 '거래할 때마다' 생긴다고 말한다. 증권거래세법 제1조는 '양도'에 과세한다. 원고는 법에 맞춰 '팔 때'로 적었다.

## 원고에서 뺀 내용

- 증권거래세율(확인 불가): 증권거래세법 제8조(1만분의 35)와 시행령 제5조(유가증권시장 1만분의 5, 코스닥시장 1만분의 20, 코넥스시장 1만분의 10)는 확인했다. 그러나 농어촌특별세법 제5조 ① 5호(증권 양도가액의 1만분의 15)가 어느 시장에 붙는지 정한 시행령 조문은 찾지 못했다(시행령 제4조 ③은 비과세 조항의 '유가증권시장'만 정함). 시장별 실제 합계 세율을 확정하지 못해 뺐다.
- 국내 상장주식 매매차익의 양도소득세: 소득세법 제94조 ① 3호 가목이 대주주의 양도와 대주주가 아닌 사람의 '증권시장 밖' 양도만 과세 대상으로 정한 것은 확인했다. 대주주 기준(시행령)과 해외주식 과세를 함께 설명해야 해서 글 길이 때문에 뺐다.
- 대체거래소(넥스트레이드) 거래 시간: 공식 자료를 확인하지 않아 넣지 않았다. 원고의 시간은 한국거래소 정규시장 기준이다.
- 신규상장 첫날의 가격 결정 방식, 우선주의 의결권, 시가총액 기준 대형주·중소형주 구분: 신규상장 첫날은 확인하지 않았고, 나머지는 원문이 있으나 글 범위를 넘어 뺐다.
- 증권회사 수수료: 금감원 '거래비용' 설명에 수수료가 없어 처음 원고의 '증권회사 수수료'를 검수에서 뺐다.
