# 투자 인사이트 화면 개편: 주가 차트·지수 띠·랭킹·스크롤 모션

- 날짜: 2026-10-26 · 결정한 사람: (리드 승인 대기) · 관련: Issue #(번호), PR #(번호)
- 상태: 구현 전 스펙 제안. 리드 검토·병합 뒤 구현한다.
- 영향: 웹 프론트(`/invest`), 웹 백엔드(market·ingest), API 계약. 앱·시연(`mobile-demo/`)은 범위 밖이다.
- 기준: PRD F1·F5·§5, [투자 인사이트 분리 결정](2026-10-26-investment-practice.md), [10-24 결정 ①](../product/decisions.md), 02 §5-4·§6·§7-3, web-api.yaml `/market/*`.

## 결정

1. **`/invest`(투자 인사이트)는 주가를 보는 화면이 된다.** 차트의 세로축을 내 돈 평가액에서 **주가(원)**로 바꾼다. 사건 핀·상세 패널은 그대로 쓴다. 기본은 시가총액 1위 종목 하나, 기간 3개월이다. 기간은 3개월·6개월·1년·3년이다.
2. **금액 계산 UI를 이 화면에서 뺀다.** 넣는 방식·금액·시드머니 입력과 넣은 돈·평가액·차이 숫자 칸을 없앤다. 금액을 넣어 보는 연습은 투자 시뮬레이션(`/simulation`)이 맡는다. `POST /simulations/run`과 계산 규칙(policies §2)은 바꾸지 않고 API로 남긴다.
3. **여러 종목은 작은 차트 여러 개로 보여 준다.** 종목을 최대 3개 고를 수 있고, 하나면 큰 차트, 둘 이상이면 종목마다 축이 따로 있는 작은 차트를 나란히 둔다. 가격대가 다른 종목을 한 축에 그리지 않는다. 두 개의 세로축을 한 차트에 쓰지 않는다는 규칙(02 §6-1)도 그대로 지킨다. 핀을 누르면 공통 상세 패널 하나가 열린다.
4. **화면 그래프용 주가 제공을 허용한다(10-24 결정 ①의 일부 변경).** `/market` API는 지금까지 원본 시세를 내려 주지 않았다. 앞으로는 아래 조건에서 **차트를 그리는 데 필요한 일별 종가**만 내려 준다.
   - 종목은 수집 대상(시장별 시가총액 상위 100), 기간은 최근 3년까지로 한정한다. 일별 종가 하나만 주고 시가·고가·저가·거래량은 주지 않는다.
   - 다운로드·CSV·복사용 내보내기 버튼을 두지 않는다. "표로 보기"는 월말 종가만 보여 준다.
   - 차트 아래에 서버가 준 제공처 이름과 과거 시세 고지(`PRICE_PAST`)를 늘 보인다.
   - 이전에도 `/simulations/run` 응답의 `series[].legs[].close`(주별 종가)가 브라우저에 갔다. 이번 변경은 그 범위를 일별로 넓힌다. 약관의 화면 표시·상업 이용 조건은 유료화 전에 확인한다는 원칙은 그대로다.
5. **지수 띠는 코스피·코스닥·나스닥100 ETF 세 칸이다.**
   - 코스피·코스닥은 키움 업종일봉조회(`ka20006`, `inds_cd` 001=코스피 종합, 101=코스닥 종합)로 받는다. 공식 가이드에서 필드는 확인했다(지수×100 정수). 인증된 실제 응답은 아직 검증하지 않았다.
   - 나스닥은 해외 시세 수집처가 없어서, 국내 상장 나스닥100 추종 ETF 하나로 대신한다. 이름은 ETF 실제 이름(예: "TIGER 미국나스닥100")으로 표시하고 "나스닥"이라고만 쓰지 않는다. 어느 종목을 쓸지는 설정값으로 둔다.
   - 띠에는 마지막 값·전일 대비·등락률(▲▼·부호)만 보인다. 등락률로 줄을 세우지 않는다(PRD §5 수익률 순위 금지).
6. **주식 랭킹은 시가총액 순위다.** 로고는 출처와 상표 이용 조건을 확인하기 전까지 이름 첫 글자 아바타로 대신한다. 이 PR에서는 로고 이미지와 외부 로고 API를 쓰지 않는다.
7. **"테마별"은 "업종별"로 표기한다.** 키움 종목정보 리스트(`ka10099`)의 `upName`을 그대로 쓰고, #88에서 정한 분류 규칙 `KIWOOM_UPNAME_V1`을 다시 쓴다. 반도체·AI 같은 테마 자동 분류는 계속 범위 밖이다. 업종 수집은 이 화면 담당이 맡고, 지금 `PracticeSyncJob`이 받는 목록 결과를 `instruments`에도 저장하도록 넓힌다. 업종은 업종 안 시가총액 합이 큰 순서로 보이고, 각 업종 안의 종목은 시가총액 순서로 보인다. 현재 업종을 과거 기간에 적용한다는 점과 수집 대상 상위 100 안에서만 묶었다는 점을 안내한다.
8. **스크롤 모션을 투자 인사이트 화면에 한해 허용한다.** 02 §7-3의 "사용자가 누른 것에만 반응"에 예외를 하나 둔다. 영역이 화면에 처음 들어올 때 한 번 차례로 나타나고(투명도 + 짧은 이동, 280ms), 다시 숨기지 않는다. `prefers-reduced-motion`이면 모션 없이 바로 보인다. 숫자가 올라가는 표시는 스크린리더에 최종값만 읽히게 한다. 차트는 처음 그릴 때와 기간·종목을 바꿀 때 왼쪽부터 그린다(`RevealClip`).
9. **F5 첫 방문 안내를 새 화면에 맞춘다.**
   - 모달 한 장: 한 줄 설명 + 과거 시세 고지 + **[차트 보기] 하나**. 금액 입력은 없다. 이 버튼이 고지 확인을 겸하며, Esc로 닫은 것만으로는 확인으로 치지 않는다.
   - 둘러보기(`/invest?tour=1`, 내 정보의 [사용법 다시 보기])는 ① 지수 띠 ② 종목 고르기(랭킹) ③ 기간·차트 ④ 사건 핀·상세 순서다.
   - 북극성 지표의 `first_result`(01 §8, F8 이벤트, 아직 미구현)는 이 화면에서 "첫 주가 차트가 그려짐"으로 읽는다. 01 §8 문구는 F8을 구현할 때 고친다.

## 이유

- 같은 "넣었다면 지금 얼마" 계산이 `/invest`와 `/simulation` 두 곳에 있으면 메뉴 이름과 역할이 겹친다. `/invest`는 시장과 종목을 보는 화면, `/simulation`은 금액을 넣어 연습하는 화면으로 나눈다.
- 가격대가 다른 종목(수천 원 ~ 수십만 원)을 한 원 단위 축에 그리면, 낮은 가격 종목은 평평한 선이 된다. 퍼센트로 바꾸면 "세로축 = 주가(원)"라는 Issue 목표와 다르다. 그래서 종목마다 축을 따로 둔다.
- 나스닥 실제 지수는 새 제공처·약관·키 발급이 필요하고, 11/1 기능 동결 전에는 위험하다. 국내 상장 ETF는 기존 키움 일봉 수집을 그대로 쓰면서 이름을 정직하게 표시할 수 있다.
- `upName`은 업종이지 테마가 아니다. #86 결정과 같은 용어를 써야 문서와 화면이 어긋나지 않는다.
