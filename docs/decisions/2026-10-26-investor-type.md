# 투자 성향(안정형·균형형·성장형) 안내

- 날짜: 2026-10-26 · 결정한 사람: 기획(SXXNHU)·팀 · 관련: Issue #87, PR #60
- 영향: 프론트 / 백엔드(회원 저장 계약은 나중에) / 시연

## 결정

- 상위 메뉴를 액티브·패시브 투자 방식으로 나누지 않고, 사용자가 직접 고르는 **투자 성향** 세 유형(안정형·균형형·성장형)을 둔다. 성향은 **패시브(지수 ETF) : 액티브(고른 종목) 비율**(70:30 · 50:50 · 30:70)이다. 예·적금은 성향에서 뺀다.
- 성향은 사용자가 정한다. [내 투자 성향] `/type`에서 질문 10개(`/type/test`)에 답하면 가까운 성향을 **참고로** 보여 주고, 사용자가 [정하기]를 눌러야 저장한다. 질문을 건너뛰고 세 유형 중 직접 고를 수도 있고(`/type/choose`, 첫 방문 안내 마지막 단계도 같다), 언제든 바꾼다. 답은 저장하지 않는다.
- 성향 화면은 "이런 성향의 투자자들이 흔히 고르는 **상품 유형**"과 그 유형에 속한 **실제 상품 이름**을 정해진 객관 기준(시가총액 순, 기준·기준일 표시)으로 나열한다. "추천" 문구는 쓰지 않고, 가입·매수 버튼·금융사 대가·특정 상품 상단 고정은 없다.
- 개별 종목은 골라 주지 않고 투자 인사이트(`/invest`)·분산 투자·투자 시뮬레이션으로 이어 준다.
- 웹은 2026-11-18까지 운영하고 일시 중지한다. 계속 운영하면 상품명 노출 범위를 다시 정한다. 유사투자자문·금소법 해당 여부의 법률 확인은 기획이 따로 한다.
- 고른 성향은 지금 브라우저(`fx.investorType`)에 저장한다. 회원 서버 저장은 `docs/contracts/web-api.yaml`에 계약을 먼저 추가한 뒤 구현한다.

## 이유

액티브·패시브 구분(10-25 시안)은 방식 설명에 머물러 "나는 무엇을 보면 되나"에 답하지 못했다. 사용자가 스스로 고른 성향을 기준으로 전략·상품 유형·계좌를 한 화면에 모으면 첫 선택까지 거리가 짧다. 판정·추천이 아니라 사용자가 고른 성향에 맞춘 정보 나열로 두어 투자 권유로 읽히는 것을 줄인다.
