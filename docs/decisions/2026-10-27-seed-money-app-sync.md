# 웹에서 고친 시드머니를 연동한 앱에도 반영

- 날짜: 2026-10-27 · 결정한 사람: 리드(SXXNHU) · 관련: Issue #83, 앱 shinds-team7/flexable-app#187·#189
- 영향: 웹 프론트 / 웹 백엔드 / 앱 서버

## 결정

1. 연동 회원이 홈 [수정하기]로 총액을 저장하면 웹 서버가 앱 서버 `PUT /internal/v1/web-links/{linkId}/seed-money` `{total}`을 부른다. 앱은 **모아둔 돈 = 총액 − 반영한 돈 합**으로 바꾼다(반영 기록·예산 계산은 그대로). 웹은 금액을 계산하지 않는다.
2. 앱 반영에 **성공하면** 웹의 직접 수정값(`seed_money_manual`)을 지우고 앱이 돌려준 값으로 연동 값을 바꾼다. 이후 앱에서 반영하면 웹도 따라간다. 지울 직접 수정값이 없으므로 [기록 기준으로 되돌리기]는 보이지 않는다.
3. 앱 반영에 **실패하면**(앱 거절: 반영한 돈보다 작음, 앱 예산 설정 전, 장애, 앱에서 해제됨) 웹에만 저장하고 안내 문구를 보여 준다. 다시 저장하면 다시 시도한다.
4. 연동하지 않은 회원은 지금처럼 웹에만 저장한다.
5. 웹 API는 기존 `PUT /me/seed-money/manual`을 그대로 쓰고 응답에 `appSync`(applied·failed, 안내 문구)를 더한다. 새 경로를 만들지 않는다.

## 이유

- 앱 시드머니는 모아둔 돈 + 반영 기록의 합이라 반영 기록을 건드리지 않고 맞출 수 있는 값은 모아둔 돈뿐이다(앱 결정 기록 2026-10-27-web-seed-money-write).
- 성공 뒤 웹 수정값을 남기면 앱에서 이후 반영한 값이 웹에 보이지 않는다.
- 실패해도 사용자가 고친 값은 웹에서 바로 써야 하므로 저장 자체는 막지 않는다.

## 바뀌는 것

- 백엔드 `AppApiClient.updateSeedMoney`, `AppLinkService.pushSeedMoney`, `SeedMoneyService.putManual`, 프론트 `useSetSeedManual`·홈 안내 문구
- 앱 서버 계약·구현은 앱 저장소 PR #189(먼저 머지·배포돼야 연동 회원 반영이 동작한다. 그 전에는 실패로 웹에만 저장)
