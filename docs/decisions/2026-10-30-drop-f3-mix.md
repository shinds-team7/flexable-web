# F3 조합·프리셋·공유(섞어보기)를 범위에서 뺀다

- 날짜: 2026-10-30 · 결정한 사람: 사용자 · 관련: Issue #114, [10-27 화면 기본값 결정](2026-10-27-screen-defaults.md) ③
- 영향: 기획 / 웹 프론트 / 문서
- 상태: 결정, 이 PR에서 반영

## 결정

F3(조합 2개 비교·프리셋 3개 저장·공유 링크)를 만들지 않는다. PRD Must·Should에서 F3와 "공유 링크"를 뺀다. 10-27 결정 ③은 `/mix`·`/p/:id` 주소를 "자리만 남긴다"고 했으나, 이 결정으로 그 주소도 걷어낸다.

## 이유

- 10-23에 상단 메뉴에서 이미 뺐고, 구현은 한 줄도 없다(서버 코드·표·계약 없음).
- 성향 안내(F10)와 새 F7(여러 금융 조합 비교)이 "나눠 담는 감각"을 이어 받는다.
- 11/1 동결까지 남은 시간에 저장·공유(개인정보 방침·계약 변경 필요)를 새로 만들지 않는다.

## 바뀌는 것

- 코드: `/mix`, `/p/:id`, `/lab/mix` 경로와 섞어보기 전용 스타일을 삭제한다(주소로 들어가면 "찾는 화면이 없어요"). 플러스 요금표에서 프리셋·비교·종목 수 한도와 "섞어보기·공유" 문구를 뺀다.
- 문서: PRD·README 경로 표·product README·01·02·03의 F3 항목을 "삭제됨"으로 표시한다. 01~03의 F3 상세 설계(저장 한도·공유 OG·`preset_save` 이벤트 등)는 이력으로 남기고 개발 기준이 아님을 상자에 적는다.
- 지표: F8 이벤트 4종 중 `preset_save`는 만들지 않는다.

## 바뀌지 않는 것

- `/diversify`(분산 투자 시안, F10 하위 화면)는 F3가 아니므로 그대로 둔다.
- 서버 코드·DB·계약은 F3 관련 항목이 원래 없어 바뀌지 않는다. 개인정보 처리가 늘지 않으므로 방침 변경 없음.
- 나중에 조합 비교·저장이 필요해지면 새 Issue·결정 기록으로 다시 연다.
