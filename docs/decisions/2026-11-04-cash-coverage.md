미연결 출처: 은행연합회·카카오뱅크·한국투자·NH·하나·신영은 일반 봇 robots 제한, 토스는 화면 호스트와 달리 실제 데이터 호스트 api.tossbank.com의 일반 봇 robots 제한으로 자동 수집하지 않는다. 교보는 비정상 요청 제한 화면, 대신·유안타는 robots 오류로 확인 실패다. KDB·부산·그 외 시중은행은 공개 조회와 상품 상세 대조를 추가 검증해야 한다. 미래에셋 발행어음도 미연결이다. 전체 시장 완료로 표시하지 않는다.

공시 기준일·적용일·검증일은 구분한다. 원문에 없는 날짜·보호 여부·금리·금액 상한·재투자는 null이다. 금리 구간을 단일 상한으로 바꾸거나 우대를 임의 합산하지 않는다. 공개 API·계산·DB 스키마 변경은 없다.

운영 파킹/CMA는 확인 시 401이어서 아직 배포·적재 성공으로 보고하지 않는다. 운영 DB·.env는 변경하지 않는다. 실제 출처→격리 H2→공개 API 및 UI 검증과 VM 운영 배포를 구분한다. 현재 점검: `node scripts/verify-cash-coverage.mjs --cash-base http://127.0.0.1:18080/api/v1 --deposit-base https://solpa.shinhanacademy.co.kr/api/v1 --expect-parking 211 --expect-cma 12`.

저축은행중앙회는 고정 XLSX 피드가 아니다. 화면의 엑셀 버튼이 사용하는 **전체 다운로드 폼 POST**(`ratanym_0100_01.act`)의 HTML 표를 읽는다. 검색어·금리 하한 없이 모든 지급방식·가입경로를 선택한다. 내부 JSON 조회(`.jct`) 수집은 추가하지 않는다. 개인정보가 포함될 수 있는 상세 JSON·담당자 연락처는 저장하지 않는다.

robots 요청은 이 호스트에서 관측된 `307 Location: /404.html`을 파일 없음으로 취급한다. 이 특정 응답을 제외한 리다이렉트·HTML robots 응답은 실패로 처리한다. 리다이렉트를 따라가거나 봇 이름을 바꾸지 않는다. 다운로드 경로에도 robots 검사를 적용한다. 다운로드는 기존 GET 원칙에서 공식 폼 POST까지 확대하며 기존 저빈도·크기·시간 상한은 유지한다.

미래에셋의 응답은 HTTP 헤더에 EUC-KR을 지정한다. 헤더 문자셋과 HTML 메타를 사용해 디코딩하며 UTF-8로 고정하지 않는다. 구조·중복·필수 열·금리 형식이 잘못되면 출처 전체를 거부하고 기존본을 유지한다. 전체 건수는 변하므로 158을 운영 코드에 고정하지 않는다. 별도 화면에서 확인한 수는 opt-in 검증의 `CASH_FSB_EXPECTED_COUNT`로 대조할 수 있다.

다운로드 파일 자체에는 전체 건수 메타데이터가 없어, 형식상 정상인 일부 행만 반환하는 상황까지 자동 탐지하지는 못한다. 이번 전체 건수 일치는 별도 화면 조회로 확인한 결과다. 매 주기 독립적인 전체 건수 대조는 공개 화면 조회 요청 방식이 확정된 뒤 보완할 사항이다.

예금 화면은 `VITE_LUMP_SAMPLE` 비움/false일 때 실제 API를 사용한다. true 또는 종류 지정은 명시적인 시연용 설정이다. 파킹·CMA는 기존 공시 카탈로그를 유지한다. 수집 시각의 JSON 왕복에서 UTC로 바뀌던 문제를 고쳐 계약대로 `+09:00`으로 응답한다. 같은 이름의 저축은행 상품을 구별하도록 비교 버튼의 접근성 이름에 회사명도 포함한다.

## 검증과 운영의 구분

- 실제 공식 출처 → 수집기 → 격리 H2 → 공개 API: 파킹 159개 + CMA 3개. FSB 화면 전체 건수와 다운로드 건수 대조.
- 실제 운영 예금 API 읽기: 6/12/24/36개월 각각 276/361/236/186개, 합집합 432개. 기간별 회사 수 97/97/92/71개. `isSample=false`, 자료 기준일 2026-11-04. **12개월 361개를 전체 기간 상품 수로 해석하지 않는다.** 로컬 finlife 키가 없어 원천 API 재수집 완전성은 별도 확인 사항이다.
- 운영 파킹·CMA API는 확인 시 HTTP 401. 후보 브랜치의 로컬 성공은 운영 배포·적재 성공을 뜻하지 않는다. 운영 환경 변수·DB·배포는 변경하지 않았다.
- 반복 가능한 읽기 전용 점검: `node scripts/verify-cash-coverage.mjs --cash-base http://127.0.0.1:18080/api/v1 --deposit-base https://solpa.shinhanacademy.co.kr/api/v1 --expect-parking 159 --expect-cma 3`. 예상 건수는 이번에 독립적으로 확인한 값이며 다음 확인 시 갱신한다. 모든 응답 상품의 식별자 중복·필수 조건·출처·검증 시각을 검사하고 예금은 네 기간을 끝 페이지까지 읽어 합집합을 센다. 원천 시장 전체 여부는 별도이므로 보고서 `marketComplete`는 false다.
- 합성 HTTP 장애·폼 POST·EUC-KR 검증은 [Postman 절차](../../postman/README.md)를 따른다. 실제 금리를 합성 fixture에 하드코딩하지 않는다.
