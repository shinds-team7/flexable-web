# 투자 성향 5유형·설문 12문항

- 날짜: 2026-11-04 · 결정한 사람: 사용자 요청(SXXNHU) · 관련: [2026-10-26 투자 성향](2026-10-26-investor-type.md), `/type/about` 설명서
- 영향: 프론트 (백엔드·계약·앱 변경 없음)

## 결정

- 투자 성향을 3개(안정형·균형형·성장형)에서 설명서(`/type/about`)의 5개 **안정형·안정추구형·위험중립형·적극투자형·공격투자형**으로 바꾼다. id는 `stable`·`cautious`·`neutral`·`active`·`aggressive`.
- 설문은 설명서의 네 영역(자금 여건 / 투자 경험과 이해도 / 투자 목표와 태도 / 투자 기간)을 묻는 12문항으로 바꾼다. 선택지는 위험을 덜 받아들이는 쪽부터 1점씩 더하고, 합계를 0~1로 바꿔 0.2·0.4·0.6·0.8 미만으로 5유형을 나눈다.
- **설명서에 점수 기준이 없어 새로 정한 것(검토 필요)**: ① 설문 문항·선택지·배점·구간, ② 제한 규칙 2개 — "원금이 줄어드는 건 안 돼요"를 고르면 안정형, "1년 안에 쓸 돈"이면 점수와 관계없이 안정추구형까지(설명서 "공격투자형으로 나왔더라도 곧 필요한 보증금까지…" 취지). 제한이 걸리면 결과 화면에 이유를 보여 준다.
- 유형마다 패시브:액티브 비율 예시는 이미 계산해 둔 지난 3년 예시(`RATIOS`)가 있는 값만 쓴다: 100:0 · 70:30 · 50:50 · 30:70 · 0:100. 새 수치를 만들지 않는다.
- 설문을 마치면 요약 화면 없이 바로 그 유형 상세(`/type/:id`)로 이동한다(저장은 상세의 [내 성향으로 정하기]를 눌러야). 상세에 설명서의 유형 설명과 "상품을 살펴볼 때" 확인할 점을 싣고, 제한 규칙이 걸렸으면 이유를 보여 준다.
- 이전에 브라우저에 저장된 값은 `balanced`→`neutral`, `growth`→`active`로 읽는다.

## 이유

설명서가 5유형을 기준으로 바뀌어, 설문·결과가 설명서와 다르면 같은 서비스 안에서 말이 어긋난다.
