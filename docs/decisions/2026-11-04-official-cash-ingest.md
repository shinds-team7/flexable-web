# 공개 공식 페이지의 사실정보 수집: 기관 문의를 필수 단계에서 제외

- 날짜: 2026-11-04 · 결정: 사용자("기관 문의를 필수적으로 해야해? 그냥 사용하고 진행해") · 관련: #144·#145·#148, #218·#221
- 영향: 웹 백엔드 수집·출처 관리. 공개 API·계산·개인정보 항목 변경 없음.

## 결정과 범위

기관의 사전 회신을 모든 출처의 필수 조건으로 두지 않는다. 로그인 없이 공개된 공식 상품 페이지에서 금리·상품명·기간/금액 조건·공시 기준일을 읽어 기존 카탈로그에 저장한다. 수집·재사용 허가를 받았다고 표시하지 않으며, 확인되지 않은 법적 허가를 사용자 승인으로 대체했다고 기록하지 않는다. robots의 허용도 재배포 라이선스라고 해석하지 않는다.

이는 [1차 결정](2026-11-04-cash-catalog-phase1.md) 2의 기관 허가 확인 전 활성화 보류와 [11-01 결정](2026-10-31-parking-cma.md)의 공식 API 한정·출처 문의 선행 조건을 이 범위에서 대체한다. 운영자 수기 입력·공개 업로드·추정 이자 계산은 추가하지 않는다.

명시적인 수집 제한·접근 차단을 우회하거나 검색엔진으로 위장하지 않는다. 출처별 robots를 확인하고 일반 수집기에 제한된 경로는 수집하지 않는다. HTTP 403·429·5xx, 리다이렉트, robots 확인 실패, 파싱 실패 시 기존 스냅샷을 유지하며 다음 주기까지 반복 호출하지 않는다. 권리자 요청이나 이용 조건 변경을 확인하면 해당 출처를 중단·철회한다.

## 1차 실제 출처

| 출처 | 제공 사실정보 | 확인·선택 |
|---|---|---|
| [케이뱅크 플러스박스](https://www.kbanknow.com/web/product/deposit/plusbox) | 공식 금액구간별 금리 표, 조회기준일, 가입·이자 지급 조건 | 11-04 robots `User-agent: *`, `Allow: /`. 파킹 1개부터 수집 |
| [유진투자증권 챔피언CMA](https://www.eugenefn.com/ingo/igca/igca100r.do) | 자유형·자산관리형 RP 약정수익률, 보유기간별 표, 기준일·재투자 조건 | 11-04 robots HTTP 404. 개인용 RP 2개부터 수집. 법인 전용 행은 제외 |
| 카카오뱅크·한국투자증권 | 공개 상품 안내 있음 | robots가 일반 수집 봇을 `Disallow: /`로 제한하므로 활성 대상에서 제외. 다른 봇의 이름으로 호출하지 않음 |

기본 주기는 worker의 매일 10:00(KST)와 시작 시 최초/오래된 출처 확인이다. 같은 출처의 정상 검증본이 6시간 이내이면 재취득하지 않는다. 공개 페이지별 한 번만 GET하며 robots도 출처별 확인한다. 수집 User-Agent는 `FlexableWebCatalog/1.0`이다. 응답 크기·연결/전체 시간 상한을 둔다.

금리는 원문에서 파싱하며 운영 금리를 코드나 Flyway에 하드코딩하지 않는다. 금액·기간 구간은 조건 원문과 함께 보관하고, 기본/최고는 해당 상품 표 안에서만 정한다. 최고금리 적용 가능 금액의 의미가 불명확하면 `rateLimit=null`로 둔다. 공시일·적용일·예금자보호 여부가 확인되지 않으면 null로 남긴다. 수집 시각을 공시일로 대체하거나 RP를 일복리라고 가정하지 않는다.

기존 DB의 `permission_reference` 열은 호환성을 위해 유지하되 내부 값은 **수집 판단 근거**(이 결정·공식 URL·robots 확인)이며 기관 허가 증빙이 아니다. 공개 응답에는 이 내부 열을 노출하지 않는다.

## 검증

파서 합성 HTML 테스트와 실제 공식 페이지 읽기를 구분한다. HTTP 경로·robots 차단·페이지 오류 시 기존 DB 유지 검증은 로컬 Postman simulation을 대상으로 수행한다. 실제 페이지→수집기→H2 테스트 DB→공개 API 검증은 명시적인 수동 실행으로만 하며 운영 DB·환경 변수에는 접근하지 않는다. 초기 지원 기관만 제공하므로 전체 시장을 포괄한다고 안내하지 않는다.
