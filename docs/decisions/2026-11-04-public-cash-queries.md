# 공식 공개 화면의 조회 요청까지 수집 허용

- 날짜: 2026-11-04 · 사용자 결정: "전부 허용하고 다 가져오자. 기능 요구사항대로 구현 동작 전부 끝났으면 issue pr 병합까지 진행"
- 관련: #143·#144·#145·#148, #236 · 영향: 웹 수집·검증·완료 처리

## 결정

공식 상품 화면이 로그인 없이 사용하는 GET/POST 조회 요청과 JSON 응답도 수집 대상으로 삼는다. 최초 HTML의 예시·과거 금리를 현재 공시로 오인하지 않고, 실제 화면의 조회 결과와 상품 유형·기준일·기간/금액 조건을 대조한다. [기존 수집 결정](2026-11-04-official-cash-ingest.md)의 페이지별 GET 한정과 [범위 기록](2026-11-04-cash-coverage.md)의 공개 조회 요청 답변 대기는 이 범위에서 대체한다. 기관 문의를 다시 필수 조건으로 두지 않는다.

수집은 공개 금융상품 사실정보에 한정한다. 인증·로그인·403/429·접근 차단을 우회하거나 검색엔진으로 위장하지 않는다. 앞서 질문에 명시한 robots 준수는 유지한다. 요청은 공식 화면에서 관측한 경로와 필드만 사용하고 기존 시간·크기 상한 및 저빈도 갱신을 유지한다. 담당자 연락처·계좌·고객 정보나 원본 JSON 전체를 저장하지 않는다.

저축은행중앙회는 화면의 전체 건수와 수집 건수를 매번 비교해 정상 형식의 부분 응답도 차단한다. CMA는 RP·발행어음형을 구분하며 MMF·MMW는 기존 1차 범위 밖이다. 미확인 금리·조건·날짜를 추정하지 않는다. 전체 기관/상품을 조사하되 읽을 수 없는 출처를 포함해 전체 시장 수집 완료라고 보고하지 않는다.

## 완료 처리

후속 사용자 답변: **"검증된 1차 기능 병합, 미연결 출처는 후속 이슈"**, **"운영서버는 내가 확인할게"**, **"끝나면 PR 병합까지"**. 검증된 1차 구현을 병합하고 전체 시장 연결·운영 적재를 완료라고 표현하지 않는다. 미연결 출처는 #245, 사용자 운영 확인은 #246, 금액별 계산/추가 유형은 #247로 추적한다. 기존 #143의 추가 필터·로고는 이 병합으로 완료하지 않는다.

robots.txt의 404 외에, 존재하지 않는 경로와 동일한 고정 오류 화면으로 이동하는 다음 응답만 파일 없음으로 처리한다. 리다이렉트는 따라가지 않는다. 상품·조회 요청의 리다이렉트는 실패다.

| 호스트 | robots 응답 | 고정 오류 위치 |
|---|---|---|
| www.fsb.or.kr | 307 | /404.html |
| m.kbsec.com | 302 | /etc/MOBI_08_0001.html |
| www.imeritz.com | 302 | https://home.imeritz.com/comm/logn/LognErrorOut.jsp |
| www.sks.co.kr | 307 | /main/common/view/CP_00030_4.jsp |

이 제한된 파일 없음 처리 외에 HTML 응답·예상하지 못한 상태/위치는 확인 실패로 처리한다. 쿼리 문자열이 있는 공식 페이지와 조회 경로도 robots 검사에 포함한다.

사용자는 완료 조건 충족 후 PR 병합과 Issue 종료를 승인했다. 기존 Issue 초안의 계산·그래프는 이미 병합된 [1차 결정](2026-11-04-cash-catalog-phase1.md)이 조회·조건 비교로 대체했다. 현재 유효 범위의 구현·실데이터·정책/계약 테스트·화면 검증·필수 CI를 확인해 완료 처리한다. 미완료 운영 확인·미연결 출처·계산 후속을 완료로 표시하지 않고 추적한다. 운영 DB·.env 직접 변경이나 Vercel 수동 운영 배포는 포함하지 않는다.
