# 가상 시뮬레이션 대회 화면 움직임: 02 §7-3 움직임 예외에 대회 메인 화면을 더한다

- 날짜: 2026-11-06 · 결정한 사람: 사용자(#285 작업 중) · 관련: Issue #285
- 영향: 웹 프론트(`/simulation` 가상 시뮬레이션 → 월간 대회 메인 화면 `VirtualContest`). 대회 판 진행 화면(`VirtualSimulation` 대회 모드)·백엔드·API 계약·앱·시연은 바뀌지 않는다.
- 기준: [02-design](../product/02-design.md) §7-3 움직임, [투자 인사이트 개편 결정](2026-10-26-invest-insight-redesign.md) ⑤·⑧, [대회 결정](2026-11-05-virtual-sim-contest.md) §7

## 배경

02 §7-3은 움직임을 "사용자가 누른 것에만 반응"으로 두고, 처음 그릴 때·스크롤할 때 저절로 움직이는 것은 투자 인사이트(`/invest`)만 예외로 둔다. #285는 대회 화면에서 숫자 카드가 차오르고 막대·주간 점수 칸이 채워지며 승급·강등 배너가 들어오는 움직임을 요구했는데, 이 예외에 들어 있지 않아 문서와 충돌했다. 사용자가 예외를 넓히기로 정했다.

## 결정

1. **대회 메인 화면도 02 §7-3 움직임 예외다.** 처음 그릴 때와 스크롤로 영역이 처음 화면에 들어올 때 저절로 움직여도 된다. 대상은 아래뿐이다.
   - 영역 등장: 참여 현황·판별 랭킹·내 판 기록·지난 대회 등 카드가 처음 화면에 들어오면 한 번 차례로 나타난다(투명도 + 짧은 이동, 나타남 280ms, 다시 숨기지 않음). `/invest`와 같은 `Reveal`을 쓴다.
   - 숫자: 잔액·매매 성과 평균·판 점수는 처음 불러올 때 0부터, 판을 끝내고 돌아왔을 때 내 순위는 이전 값부터 새 값까지 올라가거나 내려간다. 스크린리더에는 최종값만 읽힌다.
   - 막대: 오늘 목표 막대·주간 점수 칸·판별 참가자 막대(판 순서대로 시간 차)·대회 기간 막대(왼쪽부터 오늘 위치까지, 그 뒤 오늘 점)·최근 7일 하루 점수 막대(왼쪽부터 차례로)가 채워진다.
   - 강조: 승급·강등·청산 배너가 들어오고, 참여 현황의 내 판이 몇 번 은은하게 빛난다(무한 반복하지 않음).
   - 랭킹 판 탭을 바꾸면 시상대·표가 짧게 나타난다(사용자가 누른 것에 대한 반응).
2. **값은 바뀌지 않는다.** 움직임은 표시만 바꾸고 최종값은 서버 값 그대로다(ADR-3). 저절로 흐르는 띠·실시간 갱신처럼 응답에 없는 값을 암시하는 움직임은 넣지 않는다.
3. **움직임 줄이기(`prefers-reduced-motion: reduce`)면 모두 끈다.** 숫자·막대는 처음부터 최종값으로 보인다. 색은 `tokens.css` 토큰만 쓴다.
4. 대회 판 진행 화면(`VirtualSimulation`)과 다른 화면은 지금 규칙(사용자가 누른 것에만 반응) 그대로다.

## 변경 기록

- 11-11 [#418 결정](2026-11-11-contest-ux-redesign.md) 5(사용자): 대상에서 대회 기간 막대·최근 7일 하루 점수 막대를 빼고, 숫자는 잔액·리그 점수(매매 성과 평균은 보조 줄)로 바꿨다. 화면 용어는 판(티어) → 리그다.
