# 청년소식은 AI 요약 완료 후 공개한다

- 날짜: 2026-11-06 · 결정: 사용자 · 관련: #302
- 영향: 웹 프론트·백엔드. 기존 10-26 자동 게시 결정의 요약 실패 시 공개 규칙을 대체한다.

## 공개·저장 조건

- 원문과 초안은 요약 성공 여부와 관계없이 수집·저장한다. AI 요약을 잃어 수집 자체가 막히지 않는다.
- 제목·출처·지역 등 기존 필수 조건에 더해, 검사에 통과한 비어 있지 않은 AI 요약이 있어야 공개한다. 요약 대기·검사 탈락·호출 실패 소식은 목록·인기 소식·열람 집계에서 제외한다.
- 원문이 바뀌면 이전 요약을 비우고 다시 요약한 뒤 공개한다. 요약 대상 선정에는 공개 조건 대신 원문 필수 조건을 적용해 미요약 초안도 처리한다.
- 프론트는 이전 서버 응답·캐시에 남은 미요약 소식도 목록에서 제외하고 신규 저장을 막는다. 기존 저장 사본은 삭제하지 않으며 사용자가 직접 지울 수 있다.
- 키 없음·한도·호출 실패 시 공개를 보류한다. 검사를 탈락한 같은 원문은 기존처럼 자동 재시도하지 않고 원문 변경 또는 운영 재처리 때 다시 요약한다.
- 개인정보 저장 항목·외부 전송·보관 기간은 바뀌지 않는다.

## 구현 순서

계약의 `YouthNewsItem.summary`는 비어 있지 않은 문자열로 바꾸고 예시·공개 조건을 맞춘다. 이 기준 PR 병합 뒤 구현 PR에서 수집·공개·신규 저장 경계와 회귀 테스트를 반영한다.
