# 청년미래적금 계산 규칙: 입력으로 받는 일반 모델

- 날짜: 2026-11-06 · 결정: 사용자(모델 선택), 근거 확인: 신한은행 공식 상품설명서 · 관련: Issue #113
- 영향: 웹 백엔드(계산·API) / 웹 프론트(`src/data/savings.ts` 고정 예시 교체) / 문서·계약·정책
- 상태: **승인·구현됨**(리드 2026-11-07, 규칙과 가정 2건 그대로 승인). 서버 계산(`policysavings`)과 화면 연결을 구현했고 응답은 계속 `UNVERIFIED`다. 규칙은 DB 표(`policy_savings`) 대신 코드 상수에 두었다(은행별 규칙을 늘릴 때 표로 옮긴다).

## 결정

1. 청년미래적금 계산은 **특정 은행 설명서를 규칙으로 못 박지 않고 입력으로 받는 일반 모델**로 한다. 은행마다 다를 수 있는 값은 입력(`baseRate`·`bonusRate`)이거나 규칙 필드(`contributionEarnsInterest`)다. 신한 설명서는 검산의 한 예로만 쓴다.
2. 계산은 [policies §9](../policies.md)와 [`tests/policy/policy-savings.json`](../../tests/policy/policy-savings.json)을 따른다. 입금건별 예치일수로 본인 이자를 계산하고, 정부기여금에는 **기본금리만** 적용한다.
3. 원문에 없는 두 가정(일수 기준 ÷365, 기여금 입금일 = 납입한 달 말일)이 있어 응답의 `verificationStatus`는 `UNVERIFIED`다. 사람이 은행·서민금융진흥원에 확인하기 전에는 `VERIFIED`로 바꾸지 않는다.
4. 중도해지·특별중도해지·소득 심사·재직 요건은 계산하지 않고 고지만 한다.

## 공식 원문 대조(신한은행 상품설명서, 2026-06-22 기준)

이슈 #113이 요구한 4개 규칙을 원문 페이지와 대조했다. 페이지는 PDF 쪽 번호다.

| 규칙 | 원문 | 쪽 |
|---|---|---|
| 기여금 적립·지급 시점 | 정부기여금은 서민금융진흥원이 지급하고, 만기 이후 해지한 가입자에게 지급한다. 특별중도해지한 경우도 지급 대상이다(기여율은 가입기간만큼 차감) | 9, 8 |
| 기여금 이자 | 정부기여금에도 기본이자율을 지급한다. 해당 월 기여금을 진흥원이 은행에 입금한 날부터 만기일(특별중도해지는 해지일) 전날까지 계산한다 | 4, 10 |
| 금리 구조 | 기본 연 5.0%, 우대 최대 연 3.0%(소득 0.5·재무상담 0.2·소득이체 0.3·카드 0.2·증권거래 0.5·첫 거래/연계 0.3·연계 특별 1.0), 최고 연 8.0%. 만기 전 중도해지는 우대금리 없음. 이자는 입금건별로 입금일부터 해지일 전날까지 예치일수로 계산한다 | 4~7 |
| 중도해지 | 1개월 미만 연 0.10%. 1개월 이상은 기본이자율 × (1 − 차감률) × 경과월수/계약월수, 최저 연 0.10%. 차감률 1개월 80%·3개월 70%·6개월 30%·9개월 20%·11개월 10%. 특별중도해지는 기본이자율 적용 | 6, 7 |
| 그 밖 | 월 납입 한도 매월 50만 원(연 600만 원). 일반형 기여율 6%, 우대형 12%, 유형은 가입 시 확정. 이자소득 비과세. 외국인은 기여금 비대상. 원 미만 절사는 중도해지이자에 명시 | 8~10, 7 |

이슈에 적힌 가설과의 차이: 이슈는 "기여금에는 이자 없음"이 기존 가정이고 원문은 이자를 준다는 점을 짚었다. 원문 확인으로 그 방향이 맞음을 확인했다. 이슈의 월 단위 근사(본인 이자 2,220,000원, 기여금 이자 166,500원)와 일 단위 계산(2,221,571원, 163,512원)이 같은 크기이므로 약 17만 원 차이는 기여금 이자로 설명된다. 다만 공식 확정 계산값은 아니다.

## 원문에 없어 사람이 확인할 것

- 일수 기준: 설명서는 "예치일수/계약기간"으로만 적었다. ÷365로 가정했고 윤년 처리와 건별 내림 여부는 확인 전이다.
- 기여금 입금일: "해당 월에 발생한 기여금을 진흥원이 은행에 입금한 날"이라고만 적혀 있다. 납입한 달 말일로 가정했다.
- 다른 은행: 설명서는 "각 금융기관별 우대이자율 적용 요건이 다르다"고 적었다(p.6). 기본·우대금리와 기여금 이자 여부는 은행마다 확인한다.
- 소득 심사 결과(기여율 결정)는 서버가 판정하지 않는다.
