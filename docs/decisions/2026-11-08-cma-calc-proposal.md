# CMA 예상 이자 계산 범위 (승인)

- 날짜: 2026-11-08 · 상태: **승인(리드, 2026-11-08, "제안대로")**: 재투자(복리) 미반영, 보유 기간별 금리는 2단계(유진 자산관리형만; 신한은 원문 확인 전 제외), 한화·우리WON 제외, 상품별 가입 한도는 안내 문구, 세금 15.4%. 정책(§)·계약은 구현 PR에서 만든다. · 관련: Issue #247·#245, [파킹 계산 결정](2026-11-07-parking-calc-scope-proposal.md), [CMA 범위](2026-11-07-cma-scope-expansion-proposal.md)
- 근거: 웹 서버(`solpa.shinhanacademy.co.kr`) `GET /cma/products` 11-08 응답 12개(배포 뒤 15개가 되며 교보·우리투자·다올이 더해진다)의 `conditions`·`reinvestment`와 각 사 공개 안내 페이지.
- 영향: 승인되면 정책(§)·계약(CMA 계산 필드·요청·응답)·백엔드·화면이 바뀐다. 지금은 아무것도 구현하지 않는다.

## 1. CMA 상품은 파킹통장과 무엇이 다른가

| 항목 | 파킹통장 | CMA(RP형·발행어음형) |
|---|---|---|
| 금리의 성격 | 변동 예금금리 | **입금 시점의 약정수익률**. 시장금리에 따라 바뀌고 재투자 때 그날 고시 수익률로 다시 정해진다 |
| 금리가 달라지는 조건 | 잔액 구간 | 대부분 하나의 값. 일부는 **보유 기간**(유진 자산관리형 1~15일 2.75% … 151~180일 2.90%, 신한 명품 CMA 일수 구간)에 따라 달라짐. 금액에 따라 달라지는 상품은 한화(범위만 공시)·우리WON(1천만 원 이하/초과) |
| 재투자 | 없음 | 상품마다 1일(KB 발행어음형), 30·31일(메리츠·KB RP·삼성 발행어음형), 90일(교보), 180일(유진 자산관리형), 재투자 없음(삼성 RP형) |
| 보호 | 예금자보호 대상이 많음 | **예금자보호 아님**(우리WON CMA Note는 예외로 보호 대상이라고 안내). 원금 손실 가능성 고지 필요 |
| 세금 | 15.4% | 같은 15.4% (이자소득세 14% + 지방소득세 1.4%) |

## 2. 상품별로 계산할 수 있는 정도 (11-08 응답 기준)

| 구분 | 상품 | 근거 |
|---|---|---|
| **하나의 약정수익률로 계산 가능** (11개) | KB CMA RP형·발행어음형, SK Magic CMA, 메리츠 CMA, 미래에셋 CMA RP_개인, 삼성 CMA RP형·발행어음형, 현대차 급여계좌 CMA, 유진 챔피언CMA 자유형, 교보 PLUS α CMA, 다올 CMA | 공시된 값이 하나. 단 약정수익률이 바뀔 수 있고 일부는 재투자 때 다시 정해진다 |
| **보유 기간별 금리** (2개) | 유진 챔피언CMA 자산관리형, 신한투자 명품 CMA RP | 기간 구간이 원문에 있어 일수로 금리를 고를 수 있다. 신한은 원문이 "1- 27일: 2.45% / 28일: 2.45%"로 모호해 확인이 필요하다 |
| **계산하지 않음** (2개) | 한화 Smart CMA(범위 2.45~2.60%만 공시, 구간·기본금리 미확인), 우리WON CMA Note(1천만 원 이하 3.00%·초과 2.80%이지만 구간 금리를 전체 잔액에 붙이는지 원문에 없음, 파킹 규칙과 같은 이유) | 원문에 근거 없음 |

15개 중 11개(73%)가 단일 수익률로, 2개가 보유 기간으로 계산 가능하다.

## 3. 제안

1. **1단계(단일 수익률)**: 파킹 계산과 같은 방식. 이자 = floor(잔액 × 약정수익률 × 일수 ÷ 36500), 세금 floor(이자 × 0.154). **재투자·복리는 반영하지 않고** "약정수익률이 그대로 유지된다고 가정한 예상, 재투자 때 수익률이 달라지면 결과가 달라진다"고 화면에 적는다. 대상은 위 11개.
2. **2단계(보유 기간별)**: 유진 자산관리형·신한은 "입력한 일수가 속한 기간의 금리"를 쓴다. 신한은 원문 확인 후.
3. **계산하지 않는 상품**: 한화·우리WON은 이유를 화면에 보인다(파킹과 같은 방식, `calculable=false` + `calcReason`).
4. **화면 고지**: "원금 손실 가능성이 있고 예금자보호 대상이 아니에요(상품별 확인)", "약정수익률은 입금 시점 기준이며 바뀔 수 있어요"를 결과 옆에 항상 보인다. 수익 보장·추천 표현은 쓰지 않는다.
5. 계약은 파킹과 같은 형태로 `POST /cma/simulate`(상품 id·금액·일수)와 목록의 `calculable`·`calcReason`(이미 CMA는 false로 내려가고 있음)을 활용한다.

## 4. 리드가 정해 줄 것

1. **재투자 반영**: 1단계에서 재투자(복리)를 **넣지 않고** 단순 이자로 할지, 재투자 주기(1일·30/31일 등)를 반영해 복리로 계산할지. 반영하면 "재투자 때 수익률이 지금과 같다"는 가정이 더해진다. 제안은 넣지 않는 쪽.
2. **보유 기간별 금리(유진·신한)**를 1단계에 넣을지, 2단계로 미룰지. 제안은 2단계.
3. **한화·우리WON 제외**에 동의하는지. 제안은 제외.
4. **금액 한도**: 유진은 개인 누적한도 20억 원처럼 상품마다 한도가 있는데, 계산에서 한도를 넘는 금액을 어떻게 다룰지(파킹은 한도 처리 없음). 제안은 1단계에서 계산 입력 상한만 두고 상품 한도는 안내 문구로 둔다.
5. 세금 15.4% 동일 적용에 동의하는지.

## 하지 않는 것

- 우대·특판·이벤트 금리를 계산에 넣지 않는다.
- 수익을 보장하거나 상품을 추천하는 표현을 쓰지 않는다.
- 정책·계약·fixture는 승인 전에 만들지 않는다.
