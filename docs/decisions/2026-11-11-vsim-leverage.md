# 가상 시뮬레이션 일반 판에 레버리지 2배·3배(회원 전용)

- 날짜: 2026-11-11 · 결정한 사람: 사용자(Issue #419 "정해진 것", 11-11) · 관련: Issue [#419](https://github.com/shinds-team7/flexable-web/issues/419)
- 영향: 웹 프론트(`/simulation` 가상 시뮬레이션 시작·차트·결과), 웹 백엔드(`virtualsim` 패키지), API 계약(`/virtual-sim/start`, `/virtual-sim/contests/current/rounds`, `VirtualSimSnapshot`)
- 기준: [가상 시뮬레이션 결정](2026-11-04-virtual-simulation.md), [대회 결정](2026-11-05-virtual-sim-contest.md), [policies](../policies.md) §5·8-4·8-6·8-7·8-9, [01 페르소나](../product/01-product.md) "민호"(레버리지 ETF 손실 경험)

## 결정

1. **레버리지 ETF 방식이다.** 돈을 빌리는 신용 방식이 아니어서 차입·이자·반대매매가 없다. 기초 종목(지금까지의 가상 종목 가격)의 하루 등락률에 배율을 곱한 가격으로 매매한다.
2. **배율은 1(기본)·2·3이다.** 판을 시작할 때 고르고 판 중간에는 바꿀 수 없다. 인버스(−1배 등)는 없다.
3. **회원만 2·3배를 쓴다.** 비회원이 2·3배로 시작하면 `401`이고, 1배는 지금처럼 로그인 없이 쓴다. 회원 여부는 기존 로그인 세션(요청의 로그인 토큰)으로만 본다.
4. **대회 판에는 넣지 않는다.** 대회 판 시작 요청에 1이 아닌 `leverage`가 오면 `400 VALIDATION_FAILED`다.
5. **가격 식**(정책 8-9): 기초 종목 전날 종가 `C`, 레버리지 가격 전날 종가 `L`, 그날 기초 종목의 시가·고가·저가·종가 `X` 각각에 `X_L = max(1, floor(L × (C + k × (X − C)) / C))`. 첫 봉의 `C`·`L`은 시작가 `P_0`이다. 매일 배율을 다시 맞추고 운용보수·괴리·세금은 넣지 않는다. 하루 상하한이 ±30%라 3배여도 하루 최대 −90%이고 식이 단조라 봉 순서가 유지된다. 1배는 기초 봉과 완전히 같다.
6. **매매·평가는 그대로다.** §5 평가 식, 8-7 수량 매매·주문 상한·부분 체결, 첫 봉 시가 50% 최초 매수를 레버리지 가격에 그대로 쓴다.
7. **판정 뒤 정보는 기초 종목 기준 그대로 두고 레버리지 기준을 더한다.** `movement`, 공시 직후·그다음 주 등락, 유형 통계는 기초 종목 기준이다. 레버리지 판이면 같은 두 구간의 레버리지 가격 등락(`leveragedReactionReturnRate`·`leveragedNextWeekReturnRate`)을 함께 준다. 사건 유형의 과거 통계는 기초 종목 움직임에서 온 것이기 때문이다.
8. **결과 비교**: 레버리지 판이 끝나면 같은 구간(첫 봉 시가 → 마지막 봉 종가)의 기초 종목 수익률과 레버리지 가격 수익률을 `leverageResult`로 나란히 준다. 사용자의 손익·수익률은 지금처럼 `portfolio`다.
9. **위험 고지**: 배율을 고를 때와 결과 화면에 아래 문구를 보이고, 차트·결과에 "레버리지 N배 · 가상" 배지를 붙인다. 서버 `notice`에도 레버리지 판이면 배율 가격·차입 없음·운용보수 제외 문장을 붙인다.
   - 고를 때: "레버리지 2배·3배는 기초 종목의 하루 등락률에 배율을 곱해 움직여요. 손실도 배율만큼 커지고, 오르내림이 반복되면 기초 종목이 제자리여도 손실이 날 수 있어요. 가상 종목으로 연습하는 기능이며, 실제 상품의 수익을 보여 주거나 투자를 권하지 않아요."
   - 결과: "같은 기간 기초 종목은 {a}%, 레버리지 {k}배 가격은 {b}%였어요. 차이는 매일 배율을 다시 맞추는 구조 때문이에요. 실제 레버리지 ETF는 운용보수·추적 오차 등으로 이 계산과 다를 수 있어요."

## 이유

- 페르소나 "민호"처럼 레버리지 ETF로 손실을 본 사람에게, 오르내림이 반복될 때 생기는 손실(변동성 끌림)을 가상 종목으로 직접 겪어 보게 한다. 예: 기초 종목 10,000 → 11,000 → 9,900(구간 −1%)이면 2배는 10,000 → 12,000 → 9,600(−4%), 3배는 10,000 → 13,000 → 9,100(−9%).
- 신용 방식은 차입·이자·반대매매 규칙이 새로 필요하고 §5 "차입 없음"과 부딪친다. ETF 방식은 가격만 바뀌어 매매·평가 규칙을 그대로 쓸 수 있다.
- 대회는 같은 조건에서 겨루는 것이라 배율을 섞지 않는다.
