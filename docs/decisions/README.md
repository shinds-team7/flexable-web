# 결정 기록

개발 중 내린 결정 가운데 **다른 파트(웹 프론트·웹 백엔드·앱·시연)에 영향을 주는 것**을 한 파일에 하나씩 남긴다. 작은 결정은 PR 템플릿의 "정책에 없어서 새로 내린 결정" 칸에 적는다.

- 파일 이름: `YYYY-MM-DD-짧은-제목.md`
- 기록을 더하는 PR에는 `spec-change` 라벨과 [CHANGELOG](../CHANGELOG.md) 한 줄이 필요하다. 정책·계약을 함께 바꿔야 하면 같은 PR에서 고친다.
- 2026-10-18~10-24의 팀장 확정·사용자 결정은 [docs/product/decisions.md](../product/decisions.md)에 있다. 그 파일은 그대로 두고, 새 결정은 여기에 쓴다.

양식:

```markdown
# 제목

- 날짜: YYYY-MM-DD · 결정한 사람: · 관련: Issue #, PR #
- 영향: 프론트 / 백엔드 / 앱 / 시연

## 결정
## 이유
## 바뀌는 것(문서·코드·설정)
```
