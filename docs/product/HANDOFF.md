F7 문서 변경 뒤 재확인: `npm.cmd run check:api`·`npm.cmd run typecheck`·`npm.cmd run build`·`npm.cmd --prefix mobile-demo run lint` 모두 종료 코드 0. backend `.\gradlew.bat build --no-daemon`은 BUILD SUCCESSFUL, 7개 task UP-TO-DATE(위 235개 테스트 결과 재사용, 새 실행 아님). 웹 JS 653.35kB의 500kB 초과 경고는 유지. 변경 Markdown 13개에서 추가한 로컬 링크 대상 13개 누락 없음, 전역 맞춤 제안 제외 문구 제거·새 결정 연결 확인, `git diff --check` 통과. 패키지 명세·lockfile은 바꾸지 않아 의존성 설치는 위 실행 결과를 사용했다.
