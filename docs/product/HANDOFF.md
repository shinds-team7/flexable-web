## 2026-10-25 강사님 피드백(발표·BM·참여 장치)

강사님 피드백 3가지를 정리했다. 아직 결정·구현 전이며, 각 항목의 방향을 정한 뒤 [decisions](decisions.md)에 남기고 01·bm-ideas·코드에 반영한다.

**1. 발표 때 "계좌를 연결할 것"이라고 말한다**
- 발표 로드맵에 **앞으로 계좌 연결**(보유 종목·잔액 자동 불러오기)을 넣는다. 지금은 사용자가 직접 입력·선택하는 구조라는 점과 구분해서 말한다
- 화면 문구 규칙은 그대로 둔다. 구현 전에는 화면에 "계좌 연결"을 쓰지 않는다(01 §7 R7, AGENTS.md). 발표 장표의 **향후 계획**에서만 쓴다
- 이어지는 화면: 분산 투자 시안(PR #60 `/active/diversify`)의 "내가 가진 종목"을 지금은 직접 고르고, 계좌 연결 뒤에는 자동으로 채운다고 설명하면 자연스럽다
- [ ] 연결 방식을 정한다: 마이데이터(본인신용정보관리업 허가 필요) / 허가 사업자·증권사 제휴 API / 사용자가 내려받은 거래내역 파일 올리기. 발표에서는 방식·시점을 단정하지 않는다
- [ ] 실제 구현 때는 금융 정보 수집이라 개인정보처리방침(저장 항목·보관 기간·외부 전송)과 privacy-web을 같은 PR에서 고친다

**2. 비즈니스 모델에 광고를 넣는다(강사님: 광고 넣어도 된다)**
- 지금 문서: 01 §5-4는 일반 디스플레이 광고를 **보류**로 두고, 금융사·공공 캠페인 슬롯(학습 활동 후원)만 매출 본체로 둔다. 플러스 혜택에는 이미 "광고 없음"이 있다(01 §5-3)
