## 발표 BM 장표 초안

### 1장. 첫 금융 선택 전에 먼저 연습한다

**“첫 금융 선택 전에, 내가 아낀 돈으로 먼저 연습하는 입구.”** 웹에서 상품을 이해하고 같은 돈·같은 기간으로 비교하며 검수한 근거를 읽는다. 앱은 직접 입력한 잔액·기록 기준 추정으로 오늘 쓸 돈을 보여 주고 시드머니를 만드는 입구다.

각주: 교육·후원 구성과 효과·구매 수요는 모두 가정이며 기획 단계다.

### 2장. 웹 코스 하나, 구매자 셋

**“청년은 무료로 연습하고, 기관은 그 연습을 교육에 쓰는 값을 낸다.”** 교육 좌석① 대학·청년센터 / ② 공공·기업 HR / ③ 자산형성 사업 운영기관. 같은 코스를 재사용한다. 학습 활동 후원 캠페인은 광고 매출, 개인 플러스는 첫 결제·신뢰 장치다.

각주: 구매자·좌석·계약·단가는 모두 가정이며 구매 의사·예산은 미확인이다.

### 3장. 기본 시나리오 연 4,810만원

| 매출 구성 | 기본 시나리오(공급가액) |
|---|---|
| 개인 플러스 | 900명 × 9,000원 = 810만원 |
| 교육 좌석① | 10건 × 100만원 = 1,000만원 |
| 교육 좌석② | 10곳 × 50석 × 2만원 = 1,000만원 |
| 교육 좌석③ | 2계약 × 250석 × 1만원 = 500만원 |
| 학습 활동 후원 캠페인 | 1건 × 1,500만원 = 1,500만원 |
| 합계 | 810 + 1,000 + 1,000 + 500 + 1,500 = 4,810만원 |

보수 약 717.5만원 / 낙관 약 2억 1,650만원. 구독 비중은 기본 약 16.8%(소수 첫째 자리 내림). 보상 재원은 매출 제외. 2차 회의 합의 표의 숫자로 발표한다. 전체 산식·검산은 [README §4](README.md#4-bm매출시장).

각주: 판매량·단가·매출은 모두 가정이며 이익·계약 실적이 아니다.

### 4장. 지키는 선

종목·상품 추천·판단·전망, 가입 건별 중개 수수료, 개인 데이터 판매는 없다. 기관은 개인 기록을 볼 수 없고 집계만 받는다. 학습 활동 후원은 광고로 표시하고 상품 가입 조건을 두지 않는다. 앱 안 가격·결제 링크는 없다. 해커톤은 실제 청구·보상 실행 없이 시연한다. 계약 전 로고·금융사 명칭·인증 배지는 쓰지 않는다. 없는 기능을 구현된 것으로 설명하지 않는다.

각주: 교육·후원 운영은 모두 가정이며 계약·권리 검토 전이다.

### 장치 1. 30초 시연

| 시간 | 보여 줄 것 |
|---|---|
| 0~8초 | 비로그인 랜딩 → [3년 전] 첫 결과 자동 표시(예시 표시) |

비로그인 체험 탭과 시연 계정 로그인 탭을 따로 준비한다. 공공데이터포털 활용신청 범위에서 실제 시세를 쓴다. 금융위 별도 허락은 필수가 아니다. 시연 조건 3가지를 지킨다: ① 출처 표시("금융위원회 주식시세정보, 공공데이터포털, 공공누리 제4유형") ② 원본 시세를 다운로드·API로 다시 제공하지 않고 화면 그래프·계산 결과만 표시 ③ 비상업 해커톤 시연임을 고지. 유료 구독 등 상업적 이용 전에는 KRX Data Marketplace 유료 데이터 구매가 필요하다(확정 20: 상업 시세 계약은 안정화 뒤). 금융위·KRX 서면 문의는 선택(필요할 때만)이다. 예시 데이터 대본은 시세 API 장애·데이터 문제 때의 백업으로만 준비한다. [03 §13](03-architecture.md#13-시연-대본-인터넷--폐쇄망).

### 장치 2. 경쟁 체크표 4행 + 2×2
