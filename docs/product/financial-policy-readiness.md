# 계산 정책 후속 검토 자료 — 2026-11-05

관련: #113·#247·#143·#114. **근거 조사와 검토 초안이며 승인된 계산 정책·계약이 아니다.** `policies.md`·API·fixture·현재 고정 예시를 이 문서로 대체하지 않는다. 실제 계산 구현은 확정 spec-change가 먼저다.

## #113 청년미래적금

[신한 공식 설명서](https://img.shinhan.com/sbank2016/seol/20260602000000540001LC000030.PDF)(2026-06-22 기준, 11-05 재확인)에서 확인했다. 다른 은행에 일반화하지 않는다.

| 확인 항목 | 근거·남은 확인 |
|---|---|
| 금리 | PDF p.4 기본 연 5%, p.6 최고 연 8%. 고객 납입금과 정부기여금의 적용 금리는 다르다 |
| 기여금 이자 | p.10: 정부기여금의 실제 은행 입금일부터 만기/특별해지 전일까지 기본금리로 계산. 매월 고객 납입일과 같다고 가정할 근거는 없음 |
| 일수 | p.7: 입금건별 예치일수. 일수 분모·윤년·만기 이자 절사 단위는 이 설명서만으로 확정하지 못함. 일반 중도해지의 원미만 절사 문구를 만기 전체 계산으로 확장하지 않음 |
| 해지·세금 | p.9~11: 일반·특별중도해지/자발적 퇴직/만기 후의 기여금·과세 처리가 다름. 하나의 무조건 비과세 계산으로 묶지 않음 |

아래는 기존 #113의 약 17만원 차이 가설을 재현한 **월 단위 근사**다. 가입/납입/정부기여금 실제 입금일이 없는 검산으로, 공식 만기액·새 정책 fixture가 아니다. 가정은 36회 월초 납입, 고객 연 8%, 기여금 연 5%, 기여금도 매월 고객과 동시에 입금, 비과세다. 합산 잔여 개월은 36+…+1=666이다. Decimal로 `월납입액 × 금리 × 666 ÷ 12`, 기여금은 여기에 매칭비율을 곱해 검산했다.

| 월 납입 | 유형 | 원금 | 기여금 원금 | 고객 이자 근사 | 기여금 이자 근사 | 총액 근사 |
|---|---|---:|---:|---:|---:|---:|
| 78,000원 | 일반 6% | 2,808,000 | 168,480 | 346,320 | 12,987 | 3,335,787 |
| 78,000원 | 우대 12% | 2,808,000 | 336,960 | 346,320 | 25,974 | 3,517,254 |
| 500,000원 | 일반 6% | 18,000,000 | 1,080,000 | 2,220,000 | 83,250 | 21,383,250 |
| 500,000원 | 우대 12% | 18,000,000 | 2,160,000 | 2,220,000 | 166,500 | 22,546,500 |

실제 기여금 입금이 늦어지면 위 가설과 달라진다. 추가 166,500원을 모든 가입자에게 고정 가산하거나 현재 `UNVERIFIED`를 `VERIFIED`로 바꿀 수 없다.

검토할 입력안: 은행/규칙 기준일, 가입·만기일, 실제 납입 내역, 기본/충족 우대금리, 기여금 유형과 실제 입금 내역. 미래 입금 내역이 없는 경우 추정 시나리오를 별도로 허용할지, 계산을 보류할지 제품 결정이 필요하다. 은행별 산식·윤년·절사 근거를 확보한 뒤 날짜·입금 지연·부분 납입·연 한도·특별해지 검산 fixture와 API를 먼저 승인한다. 주민번호·소득 증빙을 받는 설계는 제안하지 않는다.

## #247 파킹·CMA 계산 가능성 표

| 표본·유형 | 현재 보존하는 근거 | 계산 전에 필요한 것 |
|---|---|---|
| KDB Hi 계열 | 현재 공통 금리·이자 계산/지급·추가 이벤트 원문 | 사용자의 이벤트 충족/기간, 변경 금리 이력, 일수·절사·세금·결산 적용 |
| KDB 행복/호국보훈 | 여러 금액 구간의 현재 금리·계산/지급 원문 | 구간이 전체 잔액 적용인지 초과분 적용인지 상품별 근거. 최고금리 전체 적용 불가 |
| 케이뱅크 플러스박스 | 금액 구간·바로 이자받기·지급 원문 | 구간별 적용, 인출/추가 납입, 이자 수령 선택과 실제 결산 일정 |
| RP CMA | 개인 상품 코드·약정/재투자·보유기간 원문 | 매수·중도 출금·만기/재매수 시점, 변경 금리, 세금/절사 순서 |
| 발행어음 CMA | RP와 구분된 개인 자동투자 상품 | 해당 약정과 재투자 기간. 일반 수시/만기형 수익률로 대체 불가 |
| MMF/MMW | 현 1차 대상 밖 | 별도 제공/표시 정책 선행. 약정금리처럼 계산하지 않음 |

검토안은 상품별 근거·필수 입력을 모두 충족한 계산기만 허용하고, 나머지는 미확인 사유를 반환하는 방식이다. 계산 단위(고정 잔액/입출금 원장)·미래 금리 가정·우대 확인 방식·오류 계약은 아직 선택하지 않았다. 승인되지 않은 예상 이자를 화면이나 API에 추가하지 않는다.

## #143·#114와 운영 후속

- #143: 공시 원문 검색은 기존 응답으로 구현 가능하다. 분류형 필터는 은행별 원문→분류 근거와 미확인/조건부/가입종료 구분이 필요하다. 로고는 공식 파일의 서비스 사용 조건을 확인한 뒤 연결하며 `BankBadge.LOGOS`는 아직 비어 있다.
- #114: PRD Must 유지가 현재 기준이다. 리드가 유지(조합 2개·프리셋 3개)·축소·연기 중 선택하고 담당·시연 흐름·일정을 남겨야 한다. 이번 작업에서 어느 안도 새로 확정하지 않는다.
- #198·#246: 운영 서버 재기동·배포·DB/환경 변수는 사용자 담당이다. 11-05 읽기 전용 점검 경로에서 parking은 HTTP 502, youth-news/cma는 다른 HTTP 클라이언트에서 403이었다. 원인·배포 상태를 단정할 수 없으며 조건 응답·화면·재시작·수집 확인을 완료로 표시하지 않는다. 사용자 로그/배포 결과와 대조해야 한다.
