## 2. 합의 BM 표

전체 보수·기본·낙관 산식은 [README §4](README.md#4-bm매출시장)에 둔다. 회의에서는 공급가액·계약 단위 합의안으로 교체를 제안했다. → 팀장 결정으로 합의 표 채택(§7). 모두 가정이며 단가·구매 예산·도입 수요는 미확인이다.

| 매출원(구매자) | 기본 산식 | 연 매출(공급가액) |
|---|---|---|
| 개인 플러스(청년) | 900명 × 9,000원 | 810만원 |
| 교육 좌석① 대학·청년센터 | 10건 × 100만원(반 50석 × 2만원) | 1,000만원 |
| 교육 좌석② 공공·기업 HR | 10곳 × 50석 × 2만원 | 1,000만원 |
| 교육 좌석③ 자산형성 사업 | 2계약 × 250석 × 1만원 | 500만원 |
| 학습 활동 후원 캠페인 | 1건 × 1,500만원 | 1,500만원 |
| **합계** | 810 + 1,000 + 1,000 + 500 + 1,500 | **약 4,810만원** |

보수 67.5 + 100 + 300 + 250 + 0 = 약 717.5만원, 낙관 2,250 + 6,000 + 3,400 + 2,000 + 8,000 = 약 2억 1,650만원. 구독 비중은 각각 약 9.4% / 16.8% / 10.3%(소수 첫째 자리 내림, 기본 정수 반올림 약 17%).
공공·기업 HR 좌석은 공공기관 신규채용 약 27,000명 대비 150 / 500 / 1,700석 = 약 0.5% / 1.8% / 6.2%, 자산형성 사업은 24,145명 대비 250 / 500 / 2,000석 = 약 1.0% / 2.0% / 8.2%(소수 첫째 자리 내림). 모수·교육 요건의 공식 출처는 [BM §자산형성 사업 확인](bm-ideas.md#자산형성-사업-확인).

기관 좌석 수혜자는 개인 구독자로 다시 세지 않는다. 기관은 개인 기록을 못 보고 집계만 받는다. 보상 재원은 매출에서 제외한다. 교육 의무는 우리 도구의 구매 예산·교육 인정 근거가 아니다.

## 3. 심사용 장치

### 3-1. 30초 시연

회의 당시에는 실제 시세용·대체용 두 벌을 준비하기로 했다. 0~8초 비로그인 랜딩 → [3년 전] 예시 첫 결과, 8~16초 앱 점심 8,500원 입력 → 로그인한 웹 탭 current 감소, 16~24초 금리 변경 카드(무슨 일·근거·고지), 24~30초 핵심 메시지. 비로그인 체험 탭과 시연 계정 로그인 탭을 따로 준비한다. 대체안 선택은 당시 T1 대기였다. → 팀장 결정으로 실제 시세 사용(§7).

### 3-2. 경쟁 체크표 4행 + 2×2

- 체크 ① 내가 기록한 돈으로 돌려 보나 ② 청년 정책 적금까지 같은 납입 조건으로 비교하나 ③ 거래·가입으로 돈을 벌지 않나. → 팀장 결정으로 ②는 “그래프가 움직인 이유를 근거와 함께 보여 주나”로 원문 유지(§7).
- 축: **돈의 출처(임의 금액 ↔ 내가 기록한 돈) × 목적(사고팔기·가입 ↔ 이해·연습)**. DQYDJ·SnapTool은 ‘임의 금액 × 이해’ 칸에 둔다. → 팀장 결정으로 피칭 2×2는 DQYDJ를 빼고 국내 서비스만 남김(§7).
- 확인하지 못한 칸은 ‘없음’ 대신 **미확인**. ‘우리만 있는 칸’에는 조사 범위 단서를 붙이기로 했다. → 팀장 결정으로 해당 단서 제거·차별점 원문 유지(§7).
- 2×2를 부록으로 내리자는 의견도 있었다. 단서를 붙여 본편에 두는 안으로 정리했다. → 팀장 결정으로 단서 제거(§7). 표·장표 초안은 [BM 심사용 장치](bm-ideas.md#심사용-장치-4개).

### 3-3. 청년 실측 1장

11/2~11/4 한 번의 테스트에서 5초 테스트 인지율(서비스 설명·다른 점 한 문장), 과제 완료 n/N(수기), 첫 결과까지 시간 중앙값, 3문항 전·후 정답 수, 990원 지불 의향을 잰다. 발표 값은 모두 **[11/4 테스트 후 채움]**이다.
완료율 분모 N은 **웹 체험 시작자 전원(이탈 포함)**, 완료 n은 첫 결과 도달 성공자다. 시간 중앙값은 성공자 대상으로 n/N을 함께 적는다. 개인 점수는 공개하지 않는다. 웹 체험 시작 자동 이벤트는 당시 T5 대기이며 수기로도 테스트 가능하다고 기록했다. → 팀장 결정으로 trial_start 추가·자동 집계 사용·수기는 백업(§7).

### 3-4. 수요 지도 + 구매 검증 카드

왼쪽에 공공기관 신규채용 약 2.7만명 / 청년내일저축계좌 24,145명·교육 10시간 / 희망두배 청년통장 10,000명·연 1회 금융교육을 합치지 않고 나란히 둔다. 오른쪽에는 기관 인터뷰 n건을 관심·견적 요청·계약으로 구분한다. 인터뷰 0건이면 오른쪽 칸을 뺀다. 교육 의무를 구매 예산·이수 인정으로 넓혀 말하지 않는다. 출처는 [BM 사업 확인](bm-ideas.md#자산형성-사업-확인).
