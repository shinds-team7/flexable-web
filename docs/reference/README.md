## 와이어프레임에서 코드로 옮길 때

- 스타일: 와이어프레임 `<style>`의 클래스는 이미 `src/styles/global.css`로 옮겼다. 같은 클래스 이름(`card`, `stat`, `seg`, `chip`, `news-card`, `ev-list` 등)을 그대로 쓴다.
- 차트: 타임머신 차트(`drawTimeChart`)와 예시 데이터는 `src/charts/`, `src/data/sampleMarket.ts`에 옮겨 두었다. 주식 화면은 서버 계산 결과를 그려야 한다(AGENTS.md 규칙).
- 와이어프레임 조작 띠(`.wf-bar`)·손글씨 메모·`spec-note`는 설계 설명용이라 옮기지 않는다.
- 와이어프레임과 이미 다르게 정한 것: 홈 히어로(프로필 오른쪽, "수정하기" 링크, 시연 버튼 없음), 홈 오른쪽 레일(코스피·코스닥 → 소식, 프리셋 카드 없음), 시드머니 그래프는 꺾은선, 웹 목표는 별도 `/goal`, 테마는 기본 라이트.
- 와이어프레임과 지금 코드가 다른 것(2026-10-24): 굴려보기 하위 탭 대신 상단 메뉴 5개(투자 시뮬레이션·적금 모아보기·AI 계획 수립·청년 금융 소식·플러스), 경로 `/invest`·`/savings`·`/mix`(메뉴 없음), 투자 화면은 왼쪽 종목 목록 + 본문 안 사건 패널(오른쪽 레일·문장형 조건 바 없음), 섞어보기·공유·프리셋·기준금리 카드·적금 비교선 없음, 홈 `current`·`todaySaved` 없음. 화면별 상태는 [저장소 README 경로 표](../../README.md#경로).
- 기획 정본은 [docs/product](../product/README.md)다. 최신 결정·서버 경계와 다르면 기획 정본을 따르고 이 설계 샘플을 갱신한다.
