# 배치고사 판 기준 다시 보기(2026-11-10)

- 날짜: 2026-11-10 · 측정: 개발(rhkrqkq) · 결정: 사용자(판 기준 유지, 측정 방식) · 관련: Issue #376 2단계, [대회 결정](../decisions/2026-11-05-virtual-sim-contest.md) 2-4, [반응 창 결정](../decisions/2026-11-09-placement-reaction-window.md) "남은 확인"
- 스크립트: [`scripts/placement-cuts-sim.py`](../../scripts/placement-cuts-sim.py)(표준 라이브러리. `sim` 모의 계산, `actual` 실제 결과 집계)
- 자료: 운영 DB에서 SELECT로 내보낸 CSV(2026-11-10 17:22 KST). 수집 종목 198개, `dart_disclosures` 106,267건, AI 요약(숨기지 않은 것) 413건, 공시 주요 내용 3,353건. 회원 번호는 내보내지 않았고 원본 CSV는 저장소에 넣지 않는다.
- 결론: **판 기준 7·9를 유지한다**(사용자). 판 기준 숫자(policies §8-8 표·`placementCuts`)와 코드는 바뀌지 않는다.

## 요약

1. **배치고사는 실력을 거의 가리지 못한다.** 지금 출제 규칙(반응 창 채점, 근거 4 + 6, 유형당 3문제)으로 2만 번 출제하면 무작위로 고른 평균은 5.01개, 유형별 공시 직후 상승 비율을 미리 다 아는 경우도 5.72개다. 공시 직후 방향 자체가 운에 가깝다.
2. **"모두 ↑"의 이득은 작다.** 출제된 문제의 정답 ↑ 비율이 55.8%라 모두 ↑로 고르면 평균 5.58개(+0.58), 지금 기준으로 5천만 판 이상 28.1%(무작위 17.4%)다. 1억 판은 2.6%다.
3. **기준을 올려도 구분력은 그대로다.** 8·9로 올리면 5천만 판 이상이 무작위 5.5%·모두 ↑ 11.0%로 줄 뿐, 두 전략의 차이는 비슷하게 남는다. 시작 판은 주간 승급·강등(§8-8)으로 바로잡힌다.
4. **실제 분포는 아직 없다.** 분포 수집 기준 시점(#388 배포) 뒤에 시작한 배치고사는 0건이다. 응시자가 적어 시즌이 끝나도 맞힌 수 분포로 판단하기 어렵다(아래 "측정 방식").

## 측정 방식(사용자 결정)

- 판 기준은 **모의 계산과 제품 판단으로 정한다.** 최소 응시 수 조건은 두지 않는다. 응시 30명이면 5천만 판 이상 비율의 95% 범위가 ±15%p, 평균 맞힌 수가 ±0.56개라 전략 차이(+0.58)를 가리지 못한다.
- 실제 결과는 **확인용**이다. 시즌이 끝나면 `actual`로 한 번 돌려, 사용자가 ↑를 고르는 비율과 근거 유형·나머지 정답률(문제 단위라 응시 20명이면 200개 답)을 기록한다. 응시 수가 적다는 것을 함께 적는다.
- **분포 수집 기준 시점은 #388(PR #392, 유형별 출제 상한) 운영 배포 시각 2026-11-10 08:05:33 UTC(17:05:33 KST)** 다. VM api 컨테이너의 `StartedAt`이고, #392 머지(07:49:19Z)·#394 머지(07:59:34Z) 뒤 한 번 배포했다. 그 전에 시작한 배치고사는 이전 출제 규칙의 문제라 빼고, 채점이 나중이어도 시작 시각(`started_at`)으로 가른다.
- 운영 MySQL의 `started_at`은 **UTC**로 본다(api는 `TZ=Asia/Seoul`이지만 JDBC가 `serverTimezone=UTC`. 마지막 배치고사 `started_at` 06:37:51을 UTC로 읽으면 #388 이슈 작성 15:51 KST의 14분 전이라 맞는다는 정황 판단). 실행: `python3 scripts/placement-cuts-sim.py actual <DIR> --db-tz UTC`.

## 모의 계산

출제는 서버의 `VirtualContestQuestions`(정정 병합·보합 제외, 유형 먼저 고르기, 유형 안 설명 있는 공시 먼저)를 그대로 옮겼다. 문제 풀은 2021-11-10~2026-11-10 원공시 11,700건, 시행 2만 번(시드 376), 정답은 공시 직후(기준 봉 전날 종가 → 다음 거래일 종가) 방향이다.

| 전략 | 평균 | 표준편차 | 7·9에서 5천만 이상 | 1억 |
|---|---:|---:|---:|---:|
| 무작위 | 5.01 | 1.58 | 17.4% | 1.1% |
| 근거 유형 ↑ · 나머지 무작위 | 5.46 | 1.58 | 25.9% | 2.2% |
| 모두 ↑ | 5.58 | 1.57 | 28.1% | 2.6% |
| (참고) 유형 다수 방향 | 5.72 | 1.57 | 31.6% | 3.3% |

"유형 다수 방향"은 풀 전체의 유형별 상승 비율을 미리 아는 경우라 실제 사용자가 낼 수 있는 상한에 가깝다.

| 판 기준(5천만·1억) | 무작위(1천만 / 5천만 / 1억) | 모두 ↑ | 유형 다수 방향 |
|---|---|---|---|
| 6·9 | 62.3% / 36.7% / 1.1% | 47.6% / 49.8% / 2.6% | 44.1% / 52.7% / 3.3% |
| **7·9(유지)** | 82.6% / 16.3% / 1.1% | 71.9% / 25.4% / 2.6% | 68.3% / 28.4% / 3.3% |
| 7·10 | 82.6% / 17.3% / 0.1% | 71.9% / 27.7% / 0.3% | 68.3% / 31.2% / 0.4% |
| 8·9 | 94.5% / 4.5% / 1.1% | 89.0% / 8.4% / 2.6% | 87.4% / 9.3% / 3.3% |
| 8·10 | 94.5% / 5.4% / 0.1% | 89.0% / 10.7% / 0.3% | 87.4% / 12.2% / 0.4% |

| 문제 풀 | 공시 수 | 공시 직후 ↑ | 설명 있음 | 설명 있음 ↑ |
|---|---:|---:|---:|---:|
| 근거 유형(공급 계약·자기주식 취득·시설·지분 투자) | 3,048 | 0.5522 | 1,672 | 0.5568 |
| 전체 | 11,700 | 0.5142 | 2,466 | 0.5401 |

- 시험 한 번에 근거 유형은 평균 5.4문제(세 유형 각 1.8), 나머지 유형은 각 약 0.5문제다.
- **"설명 있는 공시 먼저"의 쏠림은 작다.** 출제된 문제의 정답 ↑ 비율이 55.8%이고, 유형 안 순서를 무시하면 54.3%다. 같은 계산을 AI 요약이 0건인 로컬 사본(11-09)으로 하면 58.5%였다. 설명이 자기주식 취득(↑ 0.63)에만 있을 때 쏠림이 컸고, 운영처럼 공급 계약·시설에도 설명이 붙으면 줄어든다. AI 요약이 더 쌓이면 다시 잴 수 있다.
- **1단계 잔여 분류 항목**(자기주식취득결과보고서 169건, 주권매매거래정지 40건, `[첨부추가]` 53건)은 빼도 평균이 0.05개 안에서 움직여 분류를 고칠 근거가 되지 않는다.
- 11-05 5거래일 기준 계산(무작위 83%·16%·1%, 유형 경향대로 평균 5.45개)과 무작위 분포는 거의 같다. 채점 구간이 바뀌어도 "운의 몫이 커서 기준을 높게 잡고 실력은 주간 승급으로 가린다"(대회 결정 "이유")는 그대로다.

## 실제 결과

운영에 채점된 배치고사는 7건이고 모두 기준 시점 전에 시작해 빠졌다. 기준 시점 뒤 응시는 0건이다.

## 한계

- 서버의 수집 종목은 상위 목록(`topLimit`) 안 종목이라 스크립트의 종목(`cap_rank` 있는 수집 종목)과 조금 다를 수 있다. 서버 문제 풀 캐시 시점 차이도 무시했다.
- 전략은 기계적인 규칙이다. 실제 사용자는 AI 요약·주요 내용을 읽고 고르므로 다를 수 있고, 그 차이는 실제 결과의 ↑ 고른 비율·정답률로만 볼 수 있다.
- 채점하면 문제 사본을 지워 결과에 유형이 없다. `actual`은 회사명·날짜로 같은 날 공시 유형을 되찾고, 못 찾으면 "알 수 없음"으로 둔다.
